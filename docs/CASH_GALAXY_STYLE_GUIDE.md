## Part A — 일반 문법 (모든 기업 공통)

### A0. 3대 원칙
1. **주석 카드 3조건** — ① 초보자도 이해되는 쉬운 설명 ② 표·숫자를 직관적으로 풀어낸 시각화 ③ **은하수 큰 그림과의 유기적 연결** (그 주석이 어느 매듭·어느 숫자를 설명하는지 분명할 것). 셋 다 만족 못 하면 카드 채택 불가.
2. **완전한 유기적 연결** — 손익계산서·현금흐름표·자본변동표·재무상태표의 각 줄이 그것을 설명하는 주석과 이어지고, **모든 대분류 금액 = 하위 항목의 합**이 한 치도 어긋나지 않는다 (A6).
3. **억지 매핑 금지** — 가능한 한 많은 주석을 은하수에 매핑하되, 유기적으로 연결되지 않거나 순수 서술인 주석은 은하수 밖으로(4탭 체계에서는 **탭④**). "많이"보다 "**억지 없이, 이해되게**"가 우선.

### A1. 초심자 0단계 (인트로 고정 콘텐츠 — 회사명만 치환)
은하수를 보여주기 **전에** 세 가지를 짧게 깔아준다:
1. **재무제표 4종 한 줄 소개** (문구 고정): 손익계산서 = "1년 동안 얼마 벌고 얼마 썼나 — 장사 성적표예요." / 현금흐름표 = "통장에 실제로 돈이 얼마 들어오고 나갔나 — 입출금 내역이에요." / 자본변동표 = "주주의 몫(자본)이 1년 새 어떻게 늘고 줄었나예요." / 재무상태표 = "오늘 이 순간 회사가 가진 재산과 빚의 목록이에요." + 핵심 한 줄: "이 이야기의 핵심은 '손익 성적표의 이익'과 '통장의 현금'이 왜 다른가예요."
2. **'연결' 기준 한 문장**: "이 숫자들은 <회사명> 혼자가 아니라, <회사명>와 자회사들을 하나로 합친 '연결' 기준이에요."
3. **색 범례 상시 노출** (A2의 6칩) — 초심자는 범례 없이 색 문법을 못 읽는다.

### A3. 은하수 형태 규칙
- **사행(meander)**: 줄기가 화면 폭 8~92%를 오가며 큰 S자 스윙 3~4회. 거의 수직인 "길(road)" 금지. 부드러운 곡선(각짐·급회전 금지). 굽이의 오목한 안쪽에 재무제표 패널을 앉힌다.
- **굵기 = 금액 (√스케일 + 최소 두께)**: 정비례로 그리면 작은 갈래(환율 등)가 사라진다. 삼성 기준 굵기비(매출원가 58 · 판관비 40 · 투자 36 · 재무 16 · 운전자본 13 · 법인세 9 · 환율 6)는 **비율의 감각 기준**이고, 타사 값은 계획서 D10의 clamp 스케일 함수가 산출.
- **본류 두께 스토리텔링**: 매출(가장 굵게) → 비용 갈래로 갈라지며 가늘어짐 → 당기순이익(가장 가늚) → 비현금 조정 합류 후 다시 굵어져 영업CF(굵게). "손익상 이익보다 현금이 많다/적다"가 **두께 자체로** 보이게.
- **유출 vs 유입**: 유출 갈래 = 코랄(줄기에서 완만히 갈라져 나감), 유입 갈래 = 시안(줄기로 **되돌아 합류**).

### A4. 매듭·저수지·위성 규칙 (구조 불변식 — 생성기가 보장)
1. **저수지 분리·강조**: 기초·기말 현금은 줄기 끝의 **큰 발광 원(reservoir)** 으로 다른 매듭과 확연히 구분. 크기 √금액. 기말 저수지에 **순증 델타 칩**("+x.xx조") 합류.
2. **발원 ≠ 저수지**: 매출은 **독립 발원 성운**에서 샘솟는다 — 기초현금 저수지에서 매출이 나오면 안 됨(가는 저수지→굵은 매출 모순). 저수지엔 마지막 순증만 합류.
3. **위성 노드**: 곁다리(영업외·금융손익, 이자·세금 실납부)는 본류 매듭과 같은 크기 금지 — 작은 위성으로. 매듭이 균등 나열되면 위계가 사라진다.
4. **OCI는 손익 미경유**: 기타포괄손익은 당기순이익에서 나오면 안 된다 — **은하수 밖에서 골드 자본 갈래로 직접 합류하는 시안 점선**.
5. **감가상각 되돌아 합류**: 원가/판관비 쪽에서 빠져나간 비용이 현금 관점에선 되돌아온다 — 시안 점선 + 합류점에 **"현금은 안 나간 비용 — 도로 더해요 +x.x" 칩** (라벨 없으면 "비용이 취소됐다"로 오독).
6. **유출 도착지 라벨 필수**: 유출 갈래를 화면 밖으로 그냥 흘리지 않는다. 표준 문구 — 매출원가→"협력사·부품·재료로" · 판관비→"직원·광고·R&D로" · 법인세→"나라(세금)로" · 투자→"새 공장·장비로" · 재무(배당·자사주)→"주주에게". **부호 역전 시 조건 분기** (재무 순유입→"차입으로 조달" 등, 계획서 D10).
7. **손익 논리 순서**: `매출→…→영업이익→+영업외손익→세전이익→−법인세→당기순이익`. 감가상각을 도로 더하고 운전자본을 빼는 것은 **당기순이익 '다음'의 현금 전환 단계**(간접법) — 영업이익과 순이익 사이에 두지 말 것.
8. **자본 곁가지(골드)**: 당기순이익에서 갈라져 자본으로. 이 갈래의 배당·자사주는 재무활동 유출과 **같은 돈**임을 연결.

### A5. 재무제표 HUD 패널 규칙
- 4개 패널(IS·CF·자본변동·BS)은 **코너 브래킷 HUD 카드** 룩 — 은하수 매듭 카피와 완전히 다른 룩(혼동 금지). 색 헤더바: IS=민트/CF=시안/자본=골드/BS=스틸. 헤더에 A1의 한 줄 소개를 서브카피로.
- **흐름 따라 배치**(고정 코너 금지): 해당 매듭이 지나는 높이, 줄기가 스윙한 반대쪽(오목한 빈 쪽). 패널 겹침 금지.
- **CF 3활동은 동등 위계 — 들여쓰기 금지** (투자·재무가 영업의 하위로 보이면 안 됨).
- **자본변동표 패널엔 자본변동표만** (기초자본·NI·OCI·배당·자기주식·기말자본) — 기말 BS 혼입 금지.
- **BS는 저수지 옆 미니 패널 2개** (전기말·당기말, 자산=부채+자본 항등식).

### A6. 합계 정합 철칙 & 반올림 처리
- **철칙: 모든 대분류 금액 = 하위 항목의 합.** 합이 안 맞으면 빠진 항목을 반드시 채운다. 상습 누락 3종(삼성 사례의 일반화): ① 영업이익→순이익 사이 **영업외·금융손익과 세전이익** ② 자본변동의 **OCI** ③ 재무활동의 **차입금 순증**.
- **잔차 처리**: 하위 합이 소수점에서 안 떨어지면 "그 외 ±0.x조" 한 줄로 흡수 + 툴팁에 원본(백만원) 병기.
- **저수지 방정식**: 매듭 값을 사용자가 직접 더하게 하지 말고 **순증 델타 칩 1개**로 제시 (조 1자리 반올림 합산은 어긋나 보인다). 저수지·델타 칩만 소수 둘째 자리, 다른 매듭은 한 자리.

### A7. 카피 원칙
- **서술형 완결 문장** ("~이에요/~입니다"). 단어 나열·명사 끊기 금지 (❌ "제품을 만든 값." → ⭕ "제품을 만드는 데 든 값이에요").
- **한 매듭 = 한 호흡**. 스크롤을 내리며 차근차근.
- **비유·비교 먼저, 항목당 1개**: "1초에 약 …꼴", "매출의 xx%가 빠져나가요" — 배율·비율은 그 기업 값으로 재계산 (타사에 삼성 문구·숫자 재사용 금지).
- **용어는 그 자리에서 풀이** (표준 풀이 사전): 감가상각="손익 계산 시엔 비용으로 뺐지만 실제 현금은 안 나간 돈" · 운전자본="아직 안 들어온 외상값과 묶인 재고" · 지분법="지분을 나눠 가진 회사에서 온 몫" · 비지배지분="자회사의 다른 주주 몫" · OCI="손익을 거치지 않고 자본으로 간 평가손익" · 연결="<회사명>+자회사를 합친 기준".
- **금칙**: "장부이익" 금지 → **"손익상 이익"**. ("장부에선 뺐지만" → "손익 계산 시에는 뺐지만".)
- **자급자족 원칙**: 각 매듭 카피는 뒤쪽 주석 카드를 전제하지 않고 그 자리에서 이해되게 (전문용어 첫 등장 매듭에서 반 문장으로 풀이).

### A8. 주석 카드 & viz 선택
- **공통 템플릿 (모든 카드 동일 골격)**: ① 질문형 헤더 ② 서술 한 문단 ③ 미니 그래픽 **1개** ④ 은하수 복귀 배지. 시각 지시가 애매하면 기본형 = **가로 막대 1개 + 텍스트** (비대칭 방지).
- **viz 선택표** (콘텐츠 유형이 결정 — LLM이 고르지 않는다):

| 주석 내용 유형 | viz | 규칙 |
|---|---|---|
| 기초→증감→기말 (유형자산·이익잉여금·세금 감면) | `waterfall` | 기초·기말 앵커 필수, 잔차 "그 외" 행 |
| 구성·비중 (판관비·비용 성격별·차입 만기) | `bars` | 큰 항목부터 정렬, 최대 항목만 강조 |
| 부문별 실적 | `sectors` | **크기=매출 / 밝기=영업이익**, 내부거래 제거 행 필수 |
| 이익→현금 정산 | `steps` | 화면 진입 시 자동 재생 후 토글 |
| 양방향 상쇄 (금융수익 vs 비용) | `symmetric` | 좌우 대칭 + 순액 강조 |
| 두 시점 잔액 (관계기업·무형·FVOCI) | `delta` | 기초→기말 + 변동 사유 |
| 현금 안 된 채 묶임 (외상·재고) | `puddles` | 흐린 웅덩이 — "아직 현금 아님" 톤 |

- **표 재현 금지**: 표를 그대로 옮기지 말고 "무엇이 얼마나 늘고 줄었나 + 왜"만. 과한 은유 금지, 직관 먼저, 우주 톤은 가볍게.

### A9. 상호작용 문법
- **매듭 클릭** = 그 항목이 든 모든 재무제표 패널 숫자 **동시 발광** + "관련 주석 보기" 배지 → 카드로 스크롤.
- **카드 → 은하수 복귀 배지** (양방향 필수): 카드의 매듭 태그 클릭 시 해당 매듭으로 역스크롤 + 발광.
- **카피는 스크롤 캡션** (호버 툴팁 금지): 매듭이 화면 중앙에 오면 발광 + 카피 fade-in, 한 번에 하나씩.
- **러닝 토털 칩**: 순이익→영업CF 전환 구간에서 매듭마다 갱신되는 계산기 칩 (NI → +조정 → −운전자본 → −실납부 → =OCF).
- **"한 숫자, 세 얼굴" 동시 발광**: 감가상각처럼 여러 표에 걸친 숫자는 클릭 시 세 곳 동시 발광.

### A10. 하지 말 것 / 성공 기준
**❌ 하지 말 것**: 수직 "길" 은하수 · 패널을 매듭 카피와 같은 룩으로/고정 코너에/겹치게 · CF 들여쓰기 · 자본변동표에 BS 혼입 · 현금 저수지 구분 실패 · 저수지에서 매출 발원 · 명사 조각 카피 · "장부이익" · 표 그대로 재현 · 과한 은유 · 유출 갈래 도착지 없이 흘리기 · 카피를 호버로만 숨기기.
**✅ 성공 기준**: 주석 없이 은하수만 스크롤해도 "매출이 들어와 → 이익이 나고 → 진짜 현금으로 바뀌어 → 어디로 나가고 → 통장이 얼마 불었나"가 읽힌다 · 본류 두께로 이익↔현금 격차가 보인다 · 매핑된 주석이 특정 매듭·숫자를 설명하고 양방향으로 오간다 · 합계 정합이 어긋나지 않는다.
