# EQS V3: 재현 가능한 점수 기준

## 원칙

- M1은 이익의 현금 뒷받침을 보는 절대 기준이다.
- M2~M5는 같은 업종의 실제 재무 분포(P10/P25/P50/P75/P90)를 이용해 0~100점으로 변환한다.
- 필요한 계정이나 연도가 없으면 0점이 아니라 `None`으로 남기고, 총점은 계산 가능한 모듈의 가중 평균으로 계산한다.
- 보정 JSON에는 비교 표본 수와 분위수 경계값을 남겨 같은 입력에서 같은 점수를 다시 계산할 수 있게 한다.

## 비교군과 분위수

비금융업은 `KSIC 3자리 -> KSIC 2자리 -> 시장 전체` 순으로 유효 표본 20개 이상인 가장 좁은 비교군을 사용한다.

금융업(KSIC 64~66)은 비금융 시장과 섞지 않는다. `KSIC 3자리 -> KSIC 2자리 -> FINANCIAL` 순으로 확장하며, 마지막 `FINANCIAL`은 은행·증권·보험 등 전체 금융업 내부 표본이다. 이 확장으로 금융업의 동종업계 유효 표본 부족을 줄이되, 금융과 제조·서비스 기업을 비교하지 않는다.

P10/P25/P50/P75/P90은 해당 비교군 원시값의 10·25·50·75·90백분위 경계값이다. 높은 값이 좋은 지표는 각 경계를 0/25/50/75/100점으로, 낮은 값이 좋은 지표는 100/75/50/25/0점으로 선형 보간한다. M4는 평균 영업이익률 점수 70%와 변동폭 점수 30%를 합산한다.

## M1~M5

| 모듈 | 원시 지표 | 방향 | 기간 |
|---|---|---|---|
| M1 현금이익률 | 누적 영업현금흐름 / 누적 영업이익 | 높을수록 양호 | 최대 최근 3년 |
| M2 매출 회수 건전성 | 매출채권·계약자산 증가율 - 매출증가율 | 낮을수록 양호 | 최근 2년 |
| M3 부채 건전성 | 부채총계 / 자본총계 | 낮을수록 양호 | 최신 연도 |
| M4 본업 안정성 | 평균 영업이익률 70% + 이익률 변동폭 30% | 수익성 높고 변동성 낮을수록 양호 | 최대 최근 3년 |
| M5 자본 성장성 | 자본총계 CAGR | 높을수록 양호 | 3년이면 2년 CAGR, 2년이면 1년 성장률 |

금융업은 매출채권이 은행·보험의 수익 회수 구조를 적절히 설명하지 못하므로 M2를 설계상 제외한다. 금융업 전용 대체 모듈은 별도 검증 전까지 넣지 않는다.

## 단기 이력 보정

1·2년 이력 기업을 위해 별도의 작은 표본 분위수 표를 만들지 않는다. 기존의 충분한 업종 비교군 기준을 그대로 사용하고, 짧은 이력이 장기 추세보다 우연한 한 해에 좌우되지 않도록 점수와 종합점수 반영 비중을 중립점(50점) 쪽으로 보정한다.

| 유효 이력 | M1 | M4 | M5 | 종합점수 반영 |
|---|---:|---:|---:|---|
| 3년 | 원 점수 | 수익성+변동성 | 2년 CAGR | 100% |
| 2년 | 원 점수를 50점 방향으로 30% 축소 | 수익성+2년 변동성, 30% 축소 | 1년 자본성장, 40% 축소 | M1/M4 70%, M5 60% 가중치 |
| 1년 | 원 점수를 50점 방향으로 60% 축소 | 수익성만 사용, 60% 축소 | 계산하지 않음 | M1/M4 40% 가중치 |

M2는 2개 연도가 필요하고 M5는 최소 2개 연도가 필요하다. M3는 최신 재무상태표만 있으면 계산한다. 이력 신뢰도 가중치는 모듈의 0~100점 자체를 과도하게 확신하지 않도록 하는 장치이며, 별도의 1년용·2년용 동종업계 분위수는 만들지 않는다.

## 2026-07-20 후보 병합 재계산

- 후보 패널: 표준 OpenDART 2,607개 + 원문 구조 검증 통과 71개 + 부분 이력 5개 = 2,683개.
- 금융 내부 확장과 단기 이력 보정 적용 후: 보정 프로필 302개, 총점 산출 2,680개.
- 금융업의 동종업계 유효 표본 부족으로 인한 모듈 미산출: 0건. 금융업 M2 195건의 미산출은 설계상 제외다.
- 남은 모듈 결측은 매출·영업현금·영업이익·자본 등 실제 입력 계정 부족, 적자 기업의 M1 분모 비해석, 또는 M2에 필요한 전년 데이터 부족에 따른 것이다.

## 갱신과 검증

- 연결재무제표(CFS)를 우선하고 없으면 별도재무제표(OFS)를 쓴다.
- 매년 사업보고서 확정 후 전 상장사 패널과 보정 JSON을 함께 재생성한다.
- 원문 복구 패널은 주석 열 제외, 자산=부채+자본 회계등식, 연결·별도 출처를 검증한 뒤 후보에만 병합한다.
- 외부 산업 통계는 결과의 타당성 점검에 사용하며, 외부 평균값을 점수 cutoff로 직접 전용하지 않는다.
