# EQS V3: 재현 가능한 점수 기준

## 원칙

- M1은 이익의 현금 뒷받침을 보는 절대 기준이다.
- M2~M5는 같은 업종의 실제 재무 분포(P10/P25/P50/P75/P90)를 이용해 0~100점으로 변환한다.
- 필요한 계정이나 연도가 없으면 0점이 아니라 `None`으로 남기고, 총점은 계산 가능한 모듈의 가중 평균으로 계산한다.
- 보정 JSON에는 비교 표본 수와 분위수 경계값을 남겨 같은 입력에서 같은 점수를 다시 계산할 수 있게 한다.

## 비교군과 분위수

비금융업은 `KSIC 3자리 -> KSIC 2자리 -> 시장 전체` 순으로 유효 표본 20개 이상인 가장 좁은 비교군을 사용한다.

금융업(KSIC 64~66)은 비금융 시장과 섞지 않는다. `KSIC 3자리 -> KSIC 2자리 -> FINANCIAL` 순으로 확장하며, 마지막 `FINANCIAL`은 은행·증권·보험 등 전체 금융업 내부 표본이다. 이 확장으로 금융업의 동종업계 유효 표본 부족을 줄이되, 금융과 제조·서비스 기업을 비교하지 않는다.

P10/P25/P50/P75/P90은 해당 비교군 원시값의 10·25·50·75·90백분위 경계값이다. 높은 값이 좋은 지표는 각 경계를 0/25/50/75/100점으로, 낮은 값이 좋은 지표는 100/75/50/25/0점으로 선형 보간한다. M4는 최근 가중평균 영업이익률 점수 70%와 변동폭 점수 30%를 합산한다.

## M1~M5

| 모듈 | 원시 지표 | 방향 | 기간 |
|---|---|---|---|
| M1 현금이익률 | 누적 영업현금흐름 / 누적 영업이익 | 높을수록 양호 | 최대 최근 3년 |
| M2 매출 회수 건전성 | 매출채권·계약자산 증가율 - 매출증가율 | 낮을수록 양호 | 최근 2년 |
| M3 부채 건전성 | 부채총계 / 자본총계 | 낮을수록 양호 | 최신 연도 |
| M4 본업 안정성 | 최근 가중평균 영업이익률 70% + 이익률 변동폭 30% | 수익성 높고 변동성 낮을수록 양호 | 최대 최근 3년 |
| M5 자본 성장성 | 자본총계 CAGR | 높을수록 양호 | 3년이면 2년 CAGR, 2년이면 1년 성장률 |

금융업은 매출채권이 은행·보험의 수익 회수 구조를 적절히 설명하지 못하므로 M2를 설계상 제외한다. 금융업 전용 대체 모듈은 별도 검증 전까지 넣지 않는다.

### M2 상세

M2는 매출이 늘어난 속도보다 매출채권·계약자산이 더 빠르게 늘어나는지 확인한다. 매출은 이미 잡혔는데 아직 현금으로 회수되지 않은 금액이 과도하게 늘면, 이익의 질이 약하거나 회수 위험이 커졌을 가능성이 있기 때문이다.

```text
미수채권성 자산 = 매출채권 + 계약자산
미수채권성 자산 증가율 = (당기 미수채권성 자산 - 전기 미수채권성 자산) / 전기 미수채권성 자산
매출 증가율 = (당기 매출액 - 전기 매출액) / 전기 매출액
M2 원시값 = 미수채권성 자산 증가율 - 매출 증가율
```

M2 원시값이 낮거나 음수이면 매출 증가에 비해 회수되지 않은 채권이 과도하게 늘지 않았다는 뜻이라 양호하게 본다. 반대로 M2 원시값이 크면 매출보다 미수채권성 자산이 더 빠르게 늘었다는 뜻이라 동종업계 안에서 낮은 점수를 받는다. 수주산업처럼 계약자산이 중요한 업종은 매출채권에 계약자산을 합산해 본다.

### M4 상세

M4는 본업의 이익률이 높은지와 안정적인지를 함께 본다. 수익성은 최근 흐름을 더 반영하기 위해 최근 최대 3년 영업이익률을 1:2:3으로 가중평균한다. 변동성은 같은 기간 영업이익률의 최대값과 최소값 차이로 본다.

```text
연도별 영업이익률 = 영업이익 / 매출액
가중평균 영업이익률 = 최근 3년이면 (t-2년 이익률*1 + t-1년 이익률*2 + t년 이익률*3) / 6
2개년만 있으면 (전기 이익률*1 + 당기 이익률*2) / 3
영업이익률 변동폭 = 같은 기간 영업이익률 최대값 - 최소값

수익성 점수 = 가중평균 영업이익률을 동종업계 분위수로 환산
안정성 점수 = 영업이익률 변동폭을 동종업계 분위수로 환산
M4 = 수익성 점수*70% + 안정성 점수*30%
```

가중평균 영업이익률은 높을수록 좋으므로 P10=0점, P25=25점, P50=50점, P75=75점, P90=100점으로 환산한다. 영업이익률 변동폭은 낮을수록 안정적이므로 반대로 P10=100점, P25=75점, P50=50점, P75=25점, P90=0점으로 환산한다.

## 단기 이력 처리

1·2년 이력 기업을 위해 별도의 작은 표본 분위수 표를 만들지 않는다. 기존의 충분한 업종 비교군 기준을 그대로 사용하되, 계산 가능한 모듈 점수를 50점 방향으로 인위적으로 당기지 않는다. 대신 전년 비교나 변동성 판단이 불가능한 모듈은 `None`으로 제외하고, 총점은 실제로 계산된 모듈만 평균한다.

| 유효 이력 | M1 | M2 | M3 | M4 | M5 | 종합점수 반영 |
|---|---:|---:|---:|---:|---:|---|
| 3년 이상 | 원 점수 | 원 점수 | 원 점수 | 수익성+변동성 | 2년 CAGR | 계산 가능 모듈 원점수 평균 |
| 2년 | 원 점수 | 원 점수 | 원 점수 | 수익성+2년 변동성 | 1년 자본성장 | 계산 가능 모듈 원점수 평균 |
| 1년 | 제외 | 제외 | 원 점수 | 제외 | 제외 | M3 등 계산 가능 모듈만 평균 |

M1은 최소 2개 연도 이상의 영업현금흐름과 영업이익이 있어야 누적 현금 뒷받침을 해석한다. M2는 매출채권·계약자산 증가율과 매출증가율을 비교하므로 2개 연도가 필요하다. M4는 본업 안정성을 보는 지표라 최소 2개 연도의 영업이익률 변동폭이 필요하다. M5는 자본총계 성장률이므로 최소 2개 연도가 필요하다. M3는 최신 재무상태표만 있으면 계산한다.

짧은 이력 기업은 산출 가능한 모듈 수가 적으므로 화면에서 “계산 가능 항목 기준”임을 설명한다. 점수 자체를 보정하지 않는 이유는 짧은 이력이라는 이유만으로 우량하거나 취약한 실제 재무 신호를 중립점으로 흐리지 않기 위해서다.

## 2026-07-20 후보 병합 재계산

- 후보 패널: 표준 OpenDART 2,607개 + 원문 구조 검증 통과 71개 + 부분 이력 5개 = 2,683개.
- 금융 내부 확장, 단기 이력 처리, M4 최근 가중평균 적용 후: 보정 프로필 308개, 총점 산출 2,680개.
- 금융업의 동종업계 유효 표본 부족으로 인한 모듈 미산출: 0건. 금융업 M2 195건의 미산출은 설계상 제외다.
- 남은 모듈 결측은 매출·영업현금·영업이익·자본 등 실제 입력 계정 부족, 적자 기업의 M1 분모 비해석, 또는 M2에 필요한 전년 데이터 부족에 따른 것이다.

## 갱신과 검증

- 연결재무제표(CFS)를 우선하고 없으면 별도재무제표(OFS)를 쓴다.
- 매년 사업보고서 확정 후 전 상장사 패널과 보정 JSON을 함께 재생성한다.
- 원문 복구 패널은 주석 열 제외, 자산=부채+자본 회계등식, 연결·별도 출처를 검증한 뒤 후보에만 병합한다.
- 외부 산업 통계는 결과의 타당성 점검에 사용하며, 외부 평균값을 점수 cutoff로 직접 전용하지 않는다.
