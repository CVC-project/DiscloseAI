# UX 결정 원장 — v2 셸·SectorMap 리더 피드백 채록 (UX_DECISIONS)

> **목적**: v2 셸(갤럭시 아틀라스·SectorMap·EgoView 등)에서 리더가 내린 **모든 UI/UX 결정·기각·재설계**를
> 번호로 채록한다. 현금 은하수의 `modules/report/VARIATIONS.md`(V-###) 선례를 UI/UX에 이식한 것 —
> 같은 실수·같은 논쟁이 세션을 넘어 반복되지 않게 하는 장치다.
>
> **운영 규칙** ([CLAUDE.md](CLAUDE.md) "UX 원장 규율"):
> 1. **착수 전 필독(S0)**: v2 UI 작업 시작 전 이 원장을 읽는다 — 기각된 접근을 다시 제안하지 않기 위해.
> 2. **작업 후 기록(S7)**: 리더 피드백으로 방향이 바뀌면 그 자리에서 UX-### 항목 추가.
> 3. **2회 반복 = 승격**: 같은 판단이 2회 이상 재확인되면 원장에 머물지 말고
>    [DESIGN.md](DESIGN.md)(v2 스펙)·루트 [DESIGN.md](../../DESIGN.md)(전역 토큰) 조문 또는 코드 게이트
>    (extract_data.py V-2류 assert)로 승격하고 항목에 `→ 조문화`/`→ 코드화` 표기.
>
> **기록 형식**: `UX-###` | 일자 | 표면(셸/SectorMap/EgoView/…) | 피드백 원문 요지 → 결정 → 적용(커밋) | 상태(확정/기각/조정후보)

## EgoView — LOD-2 셸 (2026-07-28, universe/PLAN.md §5)

- **UX-013** (07-28, EgoView 밸류체인 레이어) — **상/하는 배열이 아니라 흐름(type)에서 파생한다**: ego JSON의 `layers.valuechain.up`/`down` 배열을 그대로 위/아래로 쓸지 물었더니 리더 "흐름으로 가면 될 것 같음". **결정**: 밸류체인 레이어의 세로 배치는 `up`/`down` 배열 소속이 아니라 **엣지의 `type`에서 파생** — `supply`(그 회사가 나에게 공급) = **상류=위**, `customer`(그 회사가 나의 고객) = **하류=아래**. 물자 흐름 위→아래(valuechain §5 D5) 불변. **근거**: 실측상 배열은 상/하 신호로 못 쓴다 — 전체 합이 up 1,521 / down 1,521로 완전 대칭이고(엣지 1건을 양쪽 기업 ego에 반대편으로 한 번씩 기록한 구조로 보임) 같은 상대가 한쪽엔 `customer`, 다른 쪽엔 `supply`로 들어간 사례가 있다. **UX-011과 같은 원리** — 배치는 "DB에 어느 배열/방향으로 담겼나"가 아니라 **관계의 의미**에서 나와야 한다(같은 실수 2회 → 원칙으로 승격 대상). 데이터 현황: 509사·3,042엣지·전량 T1이 이미 export에 들어와 있어 U3 토글 활성화는 GPU 없이 가능. 상태: **확정 — 구현은 U3**.
- **UX-014** (07-28, EgoView 밸류체인 레이어) — **U3 토글 활성 — 흐름색 배정·문법 구현 확정**: U-D14 계약("색=흐름 단일색, integration 배정")의 색 결정과 구현 세부. ① **흐름색 = 은백 `#e8f1ff` 단일색** — 관계 6색·재무 시맨틱 6색(루트 DESIGN.md §2)·섹터 25색 어느 축과도 혼동 없는 유일 무채 대역, "물자 흐름=중립 물류" 의미 함축. 신뢰등급은 색이 아니라 **알파·선폭·대시**로(T1 진한 실선 2px / T2 옅은 실선 1.5px / T3 점선 — 현재 데이터는 전량 T1, T2·T3는 범례에 "준비 중" 표기) ② **노드색=섹터색 유지** — 교체되는 건 엣지 문법뿐, 노드 정체성(어느 섹터 기업인가)은 레이어 불변 ③ 화살촉=오픈 셰브런(스트로크 V, 지배구조 삼각 촉과 형태 구분), 흐름 항상 위→아래(공급처→앵커→고객사) ④ 라벨=`공급처|고객사 · 금액(조/억) · 연도`, (t,type) 병합은 최신 as_of 채택(UX-013) ⑤ 토글 활성 조건=**그 기업 데이터 유무**(509/2,651만 보유 — 없으면 disabled + "밸류체인 공시 데이터 없음" 툴팁), 레이어 상태는 re-root에도 유지하되 무데이터 기업에선 지배구조로 안전 폴백 ⑥ 범례 교체(U-D14 혼합 금지): FLOW TYPOLOGY 전용 범례(선=신뢰등급·셰브런=흐름 방향·면책) ↔ EDGE TYPOLOGY 왕복 — V-3 하네스가 전환·원복 기계 검증 ⑦ 앵커명 라벨에 어두운 백킹 — VC 공급처 엣지 다발이 위로 몰릴 때 앵커명 묻힘 방지. 검증: V-3 확장 55/55 PASS(삼성전자 공급처 6+1·고객사 6+38 오라클 대조 포함). 상태: **확정 — U3 화면 구현 완료**.
