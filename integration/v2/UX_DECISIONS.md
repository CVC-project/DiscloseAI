# UX 결정 원장 — v2 셸·SectorMap 리더 피드백 채록 (UX_DECISIONS)

> **목적**: v2 셸(갤럭시 아틀라스·SectorMap·EgoView 등)에서 리더가 내린 **모든 UI/UX 결정·기각·재설계**를
> 번호로 채록한다. 현금 은하수의 `modules/report/VARIATIONS.md`(V-###) 선례를 UI/UX에 이식한 것 —
> 같은 실수·같은 논쟁이 세션을 넘어 반복되지 않게 하는 장치다.
>
> **운영 규칙** ([CLAUDE.md](CLAUDE.md) "UX 원장 규율"):
> 1. **착수 전 필독(S0)**: v2 UI 작업 시작 전 이 원장을 읽는다 — 기각된 접근을 다시 제안하지 않기 위해.
> 2. **작업 후 기록(S7)**: 리더 피드백으로 방향이 바뀌면 그 자리에서 UX-### 항목 추가.
> 3. **2회 반복 = 승격**: 같은 판단이 2회 이상 재확인되면 원장에 머물지 말고
>    [DESIGN.md](DESIGN.md)(v2 스펙)·루트 [DESIGN.md](../../DESIGN.md)(전역 토큰) 조문 또는 코드 게이트
>    (extract_data.py V-2류 assert)로 승격하고 항목에 `→ 조문화`/`→ 코드화` 표기.
>
> **기록 형식**: `UX-###` | 일자 | 표면(셸/SectorMap/EgoView/…) | 피드백 원문 요지 → 결정 → 적용(커밋) | 상태(확정/기각/조정후보)

## SectorMap — 섹터 내 밀도·LOD (2026-07-22 드릴인 사가)

- **UX-001** (07-22, SectorMap) — **섹터 named 전량 라벨 도포 = 헤어볼 기각**: universe 이전 직후 섹터당 named 49~54개를 노드+라벨로 전부 렌더 → 리더 "전체적으로 너무 징그러운 느낌". **결정**: 한 화면에 라벨 달린 노드는 소수(~10개 수준)만, 나머지는 익명 dots로 강등한다 — **named 수 ≠ 표시 수**(데이터가 많아도 화면 밀도는 캡). 상태: **확정** (이후 모든 섹터 뷰 설계의 전제).
- **UX-002** (07-22, SectorMap) — **한 화면 KOSPI/KOSDAQ 병렬 성운 기각**: UX-001 대응으로 좌=KOSPI(top10)·우=KOSDAQ(top5) 병렬 배치 구현·검증까지 마쳤으나 리더 "한 화면에 나오니 너무 어지러움" → **같은 화면에 두 클러스터를 병치하는 접근 자체 기각**(커밋 737046d는 이력 보존, 렌더는 폐기). 교훈: 밀도 캡만으로는 부족 — **한 화면 = 한 초점**. 상태: **기각**.
- **UX-003** (07-22, SectorMap) — **드릴인 LOD 확정**: 섹터 → KOSPI/KOSDAQ 성운 2덩이(개요, 프록시 노드 + `KOSPI · N사 · 클릭` 라벨) → 성운 클릭 드릴인 → 그 시장 시총 상위 ~10 named + 배경 dots. 브레드크럼 `GALAXY › 섹터 › 시장 › 기업`. 클릭 depth +1을 감수하고 화면당 초점 1개를 지킨다. 적용: 커밋 50e29cc (adapter `buildSectorMarketData` + SectorMap 2모드). 상태: **확정 — 현행 정본**.
- **UX-004** (07-22, SectorMap) — **집계 수치는 전량 기준**: SECTOR OVERVIEW "기업 수"가 화면에 그려진 named 수(15)를 보여주던 것을 섹터 전량(293)으로 교정 — **화면 밀도 캡(UX-001)과 정보 축약을 혼동하지 않는다**(그리는 건 줄여도 세는 건 전부). 성운 라벨 `N사`도 동일 원칙. 상태: **확정**.
