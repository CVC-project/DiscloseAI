## 0. 왜 lite인가 (문제 정의)

골든 1본 = **1세션 + 서브에이전트 ~34회 + 카드 중앙값 53.5장/산문 24,250자**(V-113 실측). 2,651 상장사 확장은 산술적으로 불가능하다.
그러나 **처음 보는 사람에게 필요한 건 2,651가지 서사가 아니라, 한 번 제대로 배운 표준 + 그 표준과의 차이**다.

→ **3티어 제품 구조**
| 티어 | 대상 | 산출 | 생산 |
|---|---|---|---|
| **골든(표준)** | 20 클러스터 대표 1사 | 풀 은하수 5존·딥다이브 53장 — *튜토리얼* | 1본 1세션 (기존 MILKYWAY 파이프라인) |
| **lite(델타)** | 같은 클러스터의 나머지 | 표준 대비 차이 6단 뷰 | 코드 규칙 + 카드 2~4장만 LLM |
| **scope-out** | 금융·지주·리츠·스팩·우선주 | 미제공 (계정 체계 상이) | — |

## 1. EQS 탭과의 차별 (설계 제1 게이트)

lite가 "요약 지표 나열"이 되면 **탭③ EQS와 중복**된다. EQS(firm.html)가 이미 하는 것:

> EQS 종합점수·등급 / 5개 모듈(M1 OCF÷영업이익, M2 매출채권vs매출, M3 부채비율 백분위, M4 이익률) / 수익성 지표(GPM·OPM·NPM·ROE·ROA) / **KSIC 동종 n개사 평균 대비 바차트** / 매출·OCF·순이익 시계열 / 손익·재무상태·현금흐름 3표 / 주목 포인트(severity) / 쉬운 말 3줄 요약

| 축 | 탭③ EQS | 탭② 은하수 lite |
|---|---|---|
| 비교 대상 | 동종업계 **통계**(평균·백분위) | 학습한 **표준 기업의 항로**(서사) |
| 단위 | 비율·점수 — *상태 평가* | 현금의 **경로·사건·연도** — *5년 여정* |
| 던지는 질문 | "잘하나 못하나" | "표준에서 배운 그 장면이 이 회사에선 어떻게 다른가" |
| 근거 | 정형계정 통계 | 항로 지도 + 사업보고서 **주석 원문** |

**lite 금지 목록**: 점수·등급·백분위 / ROE·ROA·마진 등 비율 나열 카드 / 업계 평균 대비 바차트 / 손익·재무상태·현금흐름 표 재현.
→ 필요하면 에필로그에서 **"지표로 평가된 성적은 EQS 재무분석 탭에서"** 크로스링크로 위임한다.

## 4. 8상 패턴 배지 — (OCF, ICF, FIN) 부호 3튜플

교과서 분류에 **초심자용 이름**을 붙인다. 배지는 최근 연도, 본문은 5년 변화 경로를 서술.

| 부호 | 이름 | 한 줄 뜻 |
|---|---|---|
| `+ − −` | **자가발전형** | 벌어서 투자하고 빚도 갚아요 (성숙 우량의 전형) |
| `+ − +` | **확장투자형** | 벌면서도 외부 자금을 더 당겨 투자해요 |
| `+ + −` | **정리형** | 벌고 자산도 팔아 빚을 갚아요 |
| `+ + +` | **비축형** | 벌고 팔고 빌리고 — 현금을 쌓는 국면이에요 |
| `− − +` | **외부수혈형** | 영업에선 못 벌고 조달로 버티며 투자해요 |
| `− + +` | **버티기형** | 영업 적자를 자산 매각과 조달로 메워요 |
| `− + −` | **구조조정형** | 자산을 팔아 빚을 갚는 국면이에요 |
| `− − −` | **소진형** | 벌지 못하는데 투자와 상환이 겹쳐 현금이 빠르게 줄어요 |

## 5. 이중 항로 지도 (차이를 즉시 인식시키는 장치)

1. **정규화 오버레이** — 이 회사 항로 위에 표준 항로를 **매출=100 정규화 고스트**로 겹친다. 규모(11조 vs 334조)가 30배 달라도 *모양* 비교가 성립한다. 토글로 표준 on/off.
2. **델타 하이라이트** — 정규화 격차가 임계 이상인 마디에 자동 배지. 색은 DESIGN.md §2 의미색 고정(mint=손익, cyan=현금, coral=유출, steel=잔액, gold=자본) — 델타의 방향은 배지 문구와 화살표로, **색을 의미 밖으로 쓰지 않는다**.
3. **양방향 앵커** — 지도 마디 클릭 → 해당 델타 카드로 스크롤 / 카드 호버 → 지도 마디 하이라이트.
4. **표준 딥링크** — 카드마다 "표준에서 이 대목 보기" → `galaxy.html?ticker=<표준>&focus=<zone>`. 골든 쪽엔 focus 파라미터 수신만 **추가**(기존 렌더 경로 무수정).

## 6. 델타 카드 — 은하수 고유 어휘 5~6장

**멘트 규격 (3문장)**: ① 표준에서는 A였어요 → ② 이 회사는 B예요 → ③ 그래서 C를 뜻해요.
**문체**: 골든과 동일 — 경어체(`~예요/~해요/~랍니다`), **격식체 금지**, 숫자는 `[브래킷]`, 용어는 그 자리에서 풀이 (STYLE_GUIDE A7). 카드마다 `anchor{zone, std_focus}`.

| 카드 | 은하수 고유 개념 | 산출 |
|---|---|---|
| **항로 개형** | 5존 총론 | 매출 강 → 영업 존 잔량 → 투자 지류 → 재무 존 방향 → 저수지. 정규화 비교 |
| **골짜기 비교** | anchor/valley | 이 회사 최저점 연도 vs 표준의 골짜기 — **같이 꺾였나(산업 사이클) / 혼자 꺾였나(개별 사정)**, 회복 여부 |
| **가장 큰 매듭** | knot | 5년 최대 단일 현금 사건(최대 투자·조달 급증 등) vs 표준의 대응 매듭 |
| **항로 전환** | 8상 경로 | 패턴이 바뀐 해와 방향 vs 표준의 불변/변화 |
| **저수지 궤적** | 순현금 누적 | 연도별 (OCF+ICF+FIN) 누적 — 쌓이는 항해인가 마르는 항해인가 |
| **가장 다른 대목** | 정규화 편차 최대 | 자동 선정 — 지도 하이라이트와 연동 |

## 7. LLM '주목할 점' 카드 (2~4장) — 유일한 LLM 구간

- **선별(코드)**: `report_section`에서 제목 시그니처로 후보 6~8개 — 재고자산·매출채권·차입금·충당부채·우발채무·특수관계자·영업부문·중단영업 등.
- **압축(2단, 골든 note-extractor→prose-writer 축소판)**: 원문을 LLM에 직접 넣지 않는다. ① 규칙 추출(표 파싱·정규식, 토큰 0) → 부족분만 ② 경량 fact 추출 → ③ 카드 작성기엔 **fact-sheet만** 입력.
- **출력**: `{title, what[2문장], why[2~3문장 — 표준에서 배운 개념으로 연결], src{note_no,title}}`
- **게이트 (D7 축소판)**: 브래킷 수치가 전부 ⑴주석 원문 substring 또는 ⑵13계정 재도출 — 실패 카드만 재작성. 대조는 코드가 DB에서 수행(토큰 0).

### 7.1 토큰 경제
- 청킹 전처리 = **기존재**(`report_section` 428,420행). 신규 임베딩 불필요.
- LLM은 **기업당 1회 배치**(사업보고서 연 1회 갱신 시 증분) → 정적 JSON 서빙 → **조회 시 토큰 0**.
- 대량 확장 시: 조회 상위 기업부터 증분 생성, GPU 서버(Qwen3-32B) 로컬 생성이면 API 토큰 0.
- 임베딩·시맨틱 검색은 **비범위** — 선별이 규칙 기반. RAG(api/) 시점의 별도 과제.

## 8. 산출물 규격

- 파일: `integration/dossier/data/galaxy_lite_<ticker>.json` — **골든 `galaxy_<t>.json`과 파일명 분리**(체커·`galaxy_index.json`·기존 무회귀 보호).
- 렌더: `integration/dossier/galaxy_lite.html` — 골든 렌더러는 5존·panels·knots 전용 React 클래스에 강결합돼 lite 스키마를 끼우는 것이 침습적. **시각 언어(tokens.css·폰트·의미색·패널 엣지)는 100% 승계**, 구조만 별도.
- 스키마 골자:
```
{ schema_version, kind:"lite",
  corp{ticker,name,fiscal_year,fiscal_label,sector,rcept_no,cash_flow_from},
  std_ref{ticker,name,cluster,adjacent:bool},
  years[], series13{...}, norm{self,std},   // 매출=100 정규화
  pattern{code,name,desc,path[]},
  cards[{id,kind:"delta",title,lines[3],anchor{zone,std_focus},nums[]}],
  notes[{id,kind:"note",title,what[],why[],src{note_no,title}}],
  meta{generated_by,validated,gate} }
```

## 9. 확장 로드맵

1. **반도체 프로토 검증** (현재) — 표준 삼성전자 → 삼성전기.
2. 검증 통과 시 **골든 보유 20 클러스터**의 잔여사부터 lite 일괄 생성 → `galaxy_index.json`(또는 lite 매니페스트)로 탭 활성.
3. **표준이 없는 섹터는 lite로 때우지 않는다** — 신규 골든을 먼저 빌드한 뒤 그 클러스터를 확장한다(리더 확정). 우선순위는 미커버 사수 기준:
   제약바이오(249) · 기계·장비(215) · 전기전자부품(197) · 화학(146) · 철강·금속(135)* · 소재(117) · 식음료(85)* · 미디어(71) · 섬유·의류(49) · 레저·교육(44) · 부동산(27) · 화장품(25) · 전문서비스(24) · 에너지(18)
   (*는 기존 골든(현대제철·CJ제일제당)과 경계 조정으로 흡수 가능 — 착수 시 판정)
4. 25섹터 ↔ 20클러스터 명칭·경계 불일치는 **과도기 매핑표**로만 표시하고, 인접 표준을 쓸 경우 화면에 **"인접 업종 표준"**을 명시한다.

## 10. 검증 게이트

4. **골든 무회귀**: 005930·015760 렌더 스모크 정상, `galaxy_index.json` 불변
5. EQS 탭과 내용 중복 없음 (§1 금지 목록 대조)
