## Part A — 일반 문법 (모든 기업 공통)

### A0. 3대 원칙
1. **딥다이브 카드 3조건** — ① 초보자도 이해되는 쉬운 설명(`what[]`) ② 표·숫자를 직관적으로 풀어낸 시각화(`why.viz`) ③ **큰 그림과의 유기적 연결**(`links[]`·`lnote` — 그 항목이 어느 매듭·어느 숫자와 맞물리는지 분명할 것). 셋 다 만족 못 하면 딥다이브 미채택.
2. **완전한 유기적 연결** — 손익계산서·현금흐름표·자본변동표·재무상태표의 각 줄이 그것을 설명하는 딥다이브와 이어지고, **모든 대분류 금액 = 하위 항목의 합**이 한 치도 어긋나지 않는다 (A6).
3. **억지 매핑 금지** — 흐름에 유기적으로 연결되는 주석은 은하수 매듭 딥다이브로, 순수 서술·측정기법·잔액 불변 주석은 **APPENDIX**(같은 탭③ 하단)로 강등. "많이"보다 "**억지 없이, 이해되게**"가 우선. (구판 "탭④" 개념 폐기 — 주석 전체가 탭③ 소관.)

### A1. 초심자 0단계 (인트로 고정 콘텐츠 — 회사명만 치환)
은하수를 보여주기 **전에** 세 가지를 짧게 깔아준다:
1. **재무제표 4종 한 줄 소개** (문구 고정): 손익계산서 = "1년 동안 얼마 벌고 얼마 썼나 — 장사 성적표예요." / 현금흐름표 = "통장에 실제로 돈이 얼마 들어오고 나갔나 — 입출금 내역이에요." / 자본변동표 = "주주의 몫(자본)이 1년 새 어떻게 늘고 줄었나예요." / 재무상태표 = "오늘 이 순간 회사가 가진 재산과 빚의 목록이에요." + 핵심 한 줄: "이 이야기의 핵심은 '손익 성적표의 이익'과 '통장의 현금'이 왜 다른가예요."
2. **'연결' 기준 한 문장**: "이 숫자들은 <회사명> 혼자가 아니라, <회사명>와 자회사들을 하나로 합친 '연결' 기준이에요."
3. **색 범례 상시 노출** (A2의 5색 + 점선) — 초심자는 범례 없이 색 문법을 못 읽는다. v6에서는 우측 카드 영역 헤더에 색 범례 고정.

### A2. 색 = 의미 문법 (고정 — 미학적 선택 금지)

| color_key | hex | 의미 |
|---|---|---|
| `mint` | #74EEC6 | 손익 (벌고 쓴 것) |
| `cyan` | #5CC7EA | 현금 |
| `gold` | #E9C46B | 자본 (주주 몫) |
| `coral` | #EC8C6A | 유출 (빠져나가는 돈) |
| `steel` | #7590B0 | 잔액/상태 (BS) |
| 점선(dash) | — | **비현금**(감가상각=시안 점선, OCI=골드 점선, 배당·자사주 실=코랄 점선) |

배경 `#05060d` · 텍스트 `--text #eef4fb`/`--dim #8fa1b6`/`--dim2 #5c6b80` · 패널 `rgba(12,17,30,.78)` · 라인 `rgba(140,170,210,.13)` · 폰트 **Pretendard**(본문) + **IBM Plex Mono**(숫자·라벨). 전부 `:root` CSS 변수(`--mint` 등)로 정의 — 코드가 `color_key`를 이 변수로 해석, JSON은 hex를 담지 않는다.

### A3. 은하수 형태 규칙 (v6 — 일직선 본류 + 직교 라우팅)
- **일직선 본류**: 본류 x는 `spineX:0.48`(화면 폭 비율)로 **고정 불변** — 구불구불 사행 금지(구판 A3 폐기). 세로로 곧게 흐른다.
- **직교 라우팅(ortho)**: 모든 지류는 수직·수평 직선으로만 그리고, 꺾이는 모서리만 곡선(반경 r10~14px). 대각선·베지어 곡선 금지.
- **굵기 = 2단 고정** (금액 무관): 본류 6px · 지류 3.5px (`CONFIG.ribbon.uniform:true`). 굵기로 금액을 말하지 않는다(스토리는 매듭 라벨·딥다이브가 전담). ⚠️ √스케일 함수(`wf`, ref 333.6)는 코드에 **잔존하나 미사용** — `uniform:false`로 바꾸면 삼성 ref 기준으로 타사가 왜곡되니 **절대 전환 금지**(uniform:true 불변).
- **유출 vs 유입**: 유출 지류 = 코랄(본류에서 직교로 갈라져 도착지로), 유입 지류 = 시안(본류로 **되돌아 합류**). 방향은 색과 라우팅으로만 표현.
- **3열 그리드 레이아웃**: `[data-grid]` = **2fr(은하수 SVG) : 3fr(재무제표 5패널) : 5fr(sticky 딥다이브 카드)**. 좌측 SVG는 `absolute inset:0`, 우측은 `sticky; top:0; height:100vh`. 반응형(CSS 변수 `--col-left/mid/right`) — 구판 1360px 고정폭·zoom 로직 전면 폐기.

### A4. 매듭·저수지·연결 규칙 (구조 불변식 — 생성기가 보장)
1. **매듭 라벨 = 이름 + 금액만** (v6): 번호(01, 02…)를 **매듭에 붙이지 않는다**(우측 카드·중앙 행에만 번호 유지). 좌측 정렬. **유입 매듭은 8px 아래 오프셋**(유출과 시각 구분).
2. **저수지 분리·강조**: 기초·기말 현금은 본류 끝의 발광 원(reservoir). 기말 위에 본류 중앙 **골드 순증칩**("+x.xx조"), 기말 아래 라벨("올해 통장") + **등식칩**("53.71+4.15=57.86"), 기초 위 레일 쪽 라벨("작년 통장").
3. **발원 = 저수지 직결**(v6 변경): 기초현금 저수지 중심에서 **시안 본류 세그먼트로 매출까지 직접 연결**(SEGS `['k1','k2']`, 배경원으로 덮어 이격 제로). 단, **매출이 기초현금에서 "나온다"는 의미가 아님** — 저수지는 출발선 앵커일 뿐, 매출은 그 해 새로 번 것(카피로 구분).
4. **OCI는 손익 미경유**: 기타포괄손익은 당기순이익에서 나오면 안 된다 — **골드 점선**으로 은하수 밖에서 자본 갈래(존 E)로 직접 합류, 칩 "손익 밖에서 직접(OCI)".
5. **감가상각 회귀선**: 원가/판관비 유출 지류 끝(k3·k5)에서 분기해 **시안 점선 직교 라우팅**으로 비현금 조정 매듭(k9)에 되돌아 합류. 합류 칩 "현금은 안 나간 비용 — 도로 더해요 +x.x"(라벨 없으면 "비용이 취소됐다"로 오독).
6. **자본 갈래(민트→존 E 골드)**: 당기순이익(k8)에서 갈라져 우측 거터(`niX=W−5`)를 타고 내려가 자본변동표 `+당기순이익` 행으로 수평 진입(민트 점선 — 손익이므로). 존 E 골드 세로줄(`gx=W−16`, 기초자본~기말자본만, 실선). 배당·자사주는 **코랄 점선**으로 재무활동과 연결, 칩 "재무활동에서 나간 그 돈".
7. **손익 논리 순서**: `매출→…→영업이익→+영업외손익→세전이익→−법인세→당기순이익`. 감가상각을 도로 더하고 운전자본을 빼는 것은 **당기순이익 '다음'의 현금 전환 단계**(간접법) — 영업이익과 순이익 사이에 두지 말 것.

### A5. 재무제표 중앙 패널 규칙 (v6 — 3열 중 가운데)
- 재무제표는 **중앙 열(3fr)에 5패널**(존 A 현금시작 · B 손익 · C 현금흐름 · D 재무상태 · E 자본변동)로 세로 배치. 각 행(`data-row`)은 클릭 시 우측 딥다이브 카드로 연결(`onRow`), 호버 시 `data-hl`.
- **행 = 이름 + 금액**, `title` 속성에 원값(백만원) 병기. 색은 항목 의미색(매출=민트/원가=코랄/현금=시안…).
- **값 색 4칙 (V-067 — 색=의미, 부호 아님)**: ① **헤드라인 행** = A2 의미색(수익·이익 민트 / 비용·유출 코랄 / 현금 시안 / 자본 골드 / BS 잔액·소계 스틸). ② **서브행(구성 내역) = 기본 무채(dim)** — 짝(수익/비용) 중 한쪽만 칠하거나 임의 강조색 금지. ③ 서브행 예외는 **다른 존과 연결되는 의미 앵커뿐**: 감가상각비=시안(비현금 파선 연결)·현금및현금성자산=시안(현금 존)·이익잉여금 등 자본 서브행=골드(골드 실 연결). ④ **부호(−/+)는 접두 기호로만** 말하고 색으로 표현하지 않는다 — gold를 강조용으로(예: R&D), cyan을 비현금 외 용도로 쓰면 위반. 존 D 총계 접두 = `자산`(스틸)·`부채`(코랄)·`자본`(골드) — 기호(Σ) 금지.
- **CF 3활동은 동등 위계 — 들여쓰기 금지**. **자본변동표(존 E)엔 자본변동만**(기초자본·NI·OCI·배당·자기주식·주식보상·기말자본) — 기말 BS 혼입 금지.
- **세부 행 펼침**(7개 그룹, 캐럿 20×20px): 판관비 8줄·영업외 5줄 등을 접었다 편다(`exp` 상태). 핀 모드에서 관련 행 자동 펼침.

### A6. 합계 정합 철칙 & 반올림 처리
- **철칙: 모든 대분류 금액 = 하위 항목의 합.** 합이 안 맞으면 빠진 항목을 반드시 채운다. 상습 누락 3종(삼성 사례의 일반화): ① 영업이익→순이익 사이 **영업외·금융손익과 세전이익** ② 자본변동의 **OCI** ③ 재무활동의 **차입금 순증**.
- **존 E 정합 강조**(v6): `402.2+45.2+6.1−9.9−8.2+0.9=436.3` — **주식보상 +0.9를 빼먹으면 0.9조가 안 맞는다**(자본변동표 5행 전부 필요).
- **잔차 처리**: 하위 합이 소수점에서 안 떨어지면 "그 외 ±0.x조" 한 줄로 흡수 + `title`에 원본(백만원) 병기.
- **저수지 방정식**: 매듭 값을 사용자가 직접 더하게 하지 말고 **순증 델타 칩 1개 + 등식칩**으로 제시(조 1자리 반올림 합산은 어긋나 보인다). 저수지·델타는 소수 둘째 자리(53.71/57.86/+4.15), 다른 매듭은 한 자리.

### A7. 카피 원칙
- **서술형 완결 문장** ("~이에요/~예요/~랍니다"). 단어 나열·명사 끊기 금지 (❌ "제품을 만든 값." → ⭕ "제품을 만드는 데 든 값이에요"). **격식체("~다.") 금지.**
- **한 매듭/카드 = 한 호흡**. `what[]`은 1~2문장, `why.body`는 1~3문장, `five.cap`은 1~3문장, `five.so`는 **정확히 1문장**.
- **비유·비교 먼저, 항목당 최대 1개**: "1초에 약 …꼴", "매출의 xx%가 빠져나가요", "재무제표는 이어달리기라서" — 배율·비율은 그 기업 값으로 코드가 재계산해 payload에 넣은 값만 인용(타사에 삼성 문구·숫자 재사용 금지).
- **숫자는 [브래킷 칩]으로**: 산문 속 금액·연도는 `[53.71조]`·`[FY23]` 형태로 감싼다(코드가 IBM Plex Mono 칩으로 렌더). 칩 속 숫자는 payload 표시 문자열만 사용.
- **용어는 그 자리에서 풀이** (표준 풀이 사전 — 첫 등장 시 필수): 감가상각="손익 계산 시엔 비용으로 뺐지만 실제 현금은 안 나간 돈" · 운전자본="아직 안 들어온 외상값과 묶인 재고" · 지분법="지분을 나눠 가진 회사에서 온 몫" · 비지배지분="자회사의 다른 주주 몫" · OCI="손익을 거치지 않고 자본으로 간 평가손익" · 연결="<회사명>+자회사를 합친 기준".
- **금칙**: "장부이익" 금지 → **"손익상 이익"**. 투자 조언류(매수·매도·추천·확실·보장) 금지. 미래 단정 금지(원문 전망은 "회사는 …라고 밝혔다" 귀속형만). 이모지·연속 느낌표 금지.
- **자급자족 원칙**: 각 카피는 뒤쪽 딥다이브를 전제하지 않고 그 자리에서 이해되게 (전문용어 첫 등장에서 반 문장 풀이).

### A8. 딥다이브 카드 & viz 8종 (콘텐츠 유형이 viz를 결정 — LLM이 고르지 않는다)
- **카드 골격**(모든 딥다이브 동일): 헤더(존 배지·이름·금액) → `what[]`(쉬운 설명) → `links[]`(맞물리는 숫자) + `lnote` → `why{sub,body,viz,cap}`(규정/시각화) → **`five`(5년간 어땠나요 — A11)**.
- **viz 선택표** (콘텐츠 유형 → viz 함수 — 코드가 배정):

| 콘텐츠 유형 | viz 함수 | 규칙 |
|---|---|---|
| 5개년 단일 추세 | `vLine` | 5점 라인, 마지막 점 밝게, 전년대비 Δ칩, `valley` 지정 시 저점 코랄 점선·라벨 |

### A11. 5개년 시계열 규칙 (v6 신규 — 타사 확장 일관성의 핵심)
> 각 딥다이브의 `five` 필드 = "④ 5년간 어땠나요". 이 절이 **기업 간 일관성이 가장 붕괴되기 쉬운 지점**(창의적 해석)이므로, **사실 판정은 코드, 문장화만 LLM, 검사는 다시 코드** 원칙을 엄격 적용한다.
- **차트 렌더**: 시계열 `S[key]`(5점, FY21~25)를 vLine/vTwin에 넣으면 자동. **당해(FY25) 강조**(마지막 점 밝게), Δ칩(전년 대비), `valley`(저점) 지정 시 코랄 점선+라벨. **음수 구간**은 `zero:true`로 0선 표시(적자·순유출 지표).
- **`five` 3형**: ⓐ `{key, cap, so}` — 단일 추세 vLine ⓑ `{twin:{a,b}, cap, so}` — 두 지표 대비 vTwin ⓒ `{skip:'사유'}` — 5점 미완성·잔차·부호 요동·비추세 지표는 차트 없이 사유 한 줄(삼성 41슬롯 중 17이 skip).
- **cap(캡션)**: 시계열의 스토리를 문장화 — 하지만 **어떤 스토리인지는 코드가 탐지**(story.py, 계획서 §6.6): 골짜기·회복(S2), 연속 증감(S4), 역설(S3: "불황에도 R&D"), 부호 특이(S1: 적자·환입), 정점 후 감소(S6) 등. LLM은 탐지된 사실(연도·낙폭%·값)을 payload 표시 문자열 그대로 인용해 **문장화만** 한다. cap엔 숫자 ≥1 필수(뭉뚱그림 방지). ⚠️ **"사상 최대" 금지**(5년 창으론 단정 불가) → "5년 새 최대"만(S5). 삼성 골든 k2가 "사상 최대"를 쓰는 것은 리더 검증 수작업 예외이며, LLM 자동 생성분엔 적용 안 됨.
- **so(인사이트)**: 한 문장. "현금 잔액은 '얼마나 벌었나'보다 '얼마나 투자했나'에 따라 출렁여요" 류의 일반화 교훈 — 유형별 인사이트 프레임 사전을 힌트로.
- **앵커 이벤트 일관성**: 한 기업의 핵심 지표들이 같은 해에 함께 꺾이면(삼성=2023 반도체 한파) 그 사건을 **canonical label 1개**로 명명(회사 브리프, 계획서 §6.6)하고 전 카드가 같은 자구를 인용 — vLine `valleyLabel`도 이 label. 제멋대로 변형("반도체 겨울" 등) 금지.
