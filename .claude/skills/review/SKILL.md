# /review — 코드 리뷰

Agent 도구로 `code-reviewer` agent를 호출하여 현재 변경된 파일을 리뷰합니다.

## 확인 항목
- 코딩 컨벤션 (CLAUDE.md 규칙 준수)
- 도메인 로직 이슈 (K-IFRS 규칙, DART API 패턴 등)
- 잠재적 버그 또는 엣지 케이스
- 다른 모듈과의 DB 인터페이스 호환성

## 출력
- 지적사항이 있으면 파일명 + 라인 번호와 함께 코멘트
- 지적사항이 없으면 "리뷰 통과" 메시지

이 skill은 코드를 수정하지 않습니다. 리뷰 결과를 보고 팀원이 판단합니다.
