## 0. 목표·비목표

**목표**: 관계가 하나도 없는 상장사 1,202사 중 ~1,011사(84%)를 채운다 — 강원랜드(자회사
전부 비상장)·케어젠(개인 대주주)처럼 데이터는 있는데 "노드는 상장사만" 원칙 때문에
비어 있는 화면을 해소한다.

**비목표 (리더 확정 — 이번 확대에서 명시적으로 안 하는 것)**:
- **비상장 노드 간 연관성 탐색 없음** — 같은 이름이 여러 회사 공시에 나와도 **병합하지 않는다**.
  각 상장사의 ego에만 로컬로 존재. "소프트웨어공제조합"이 30개사 공시에 나오면 30개의
  별개 라벨일 뿐 하나의 허브가 되지 않는다.
- **표기 통합·정규화 없음** — 공시 원문 문자열 그대로 표시(`㈜시큐아이`와 `(주)시큐아이`를
  같게 만들려는 시도를 하지 않는다). 정규화는 **상장사 링킹 시도**에만 쓰고, 실패해서
  비상장으로 떨어진 뒤에는 원문을 보존한다.
- **비상장 자체 ego·설명 없음** — DART 사업보고서 해설을 붙이지 않는다. 클릭해도 이동 없음.
- SectorMap 불변 — 비상장은 섹터·시총이 없어 지도에 올리지 않는다. 등장 표면은
  **EgoView(이웃)와 팝오버뿐**.
- 5% 미만 지분·소액 단순투자 노드화 없음 — K-IFRS 임계값 유지(케어젠→아모레퍼시픽
  2,941주류는 계속 제외).

## 2. 신원 — "연관성 없음"이 설계 전체를 단순화한다

전역 실체가 없으므로 **신원 문제 자체가 발생하지 않는다.** 원안(전역 uid·표기 통합)에서
가장 큰 리스크였던 동명 병합·표기 흔들림 2,032키·FN-013 계열 오링킹이 **설계상 소멸**한다.

- **키**: `x_` + sha1(`anchor_corp` + `|` + 원문문자열)[:12]. 앵커 스코프 합성키 —
  **upsert·prune용 내부 키일 뿐** 화면에 노출되지 않고 다른 앵커와 절대 공유되지 않는다.
- **표시**: 공시 원문 문자열 그대로(`name_raw`). 트림·개행 정리만.
- **정규화의 역할 축소**: 상장사 링킹 **시도**에만 사용. 실패 후 비상장으로 떨어지면 원문 보존.
- **방어 5층**: L1(영문 2~5자 약칭)·L2(쌍 블록리스트)는 **상장사 링킹 단계**에 그대로 유지.
  L1에 걸린 'HMA'는 이제 상장 HMM으로 붙지 않고 **"HMA"라는 비상장 라벨**이 된다 —
  공시에 적힌 그대로라 정확하고, 사고(FN-013)는 여전히 차단된다.

## 3. 데이터 모델

```
UnlistedNode (신규 — modules/relation/storage/models.py)
  uid TEXT PK          -- x_<sha1(anchor|raw)[:12]>  (내부 키, 앵커 스코프)
  anchor_corp TEXT     -- 이 노드가 등장하는 상장사 (ticker)
  name_raw TEXT        -- 공시 원문 문자열 그대로 (화면 표기)
  kind TEXT            -- private_corp / person / coop_fund / public_org
  first_seen TEXT      -- provenance (rcept_no·source_type)
  status TEXT          -- active
  UNIQUE(anchor_corp, name_raw)
```

- **RelationLocal·ValueChainEdge 스키마 불변** — source/target 컬럼에 uid를 넣는다
  (6자리 ticker와 `x_` 프리픽스로 형태 충돌 없음). 마이그레이션은 테이블 추가 1회.
- **prune 소유권 조문 준수**: 각 생산자(filters=지분, related_party=주석)가 자기 source_type
  스코프의 UnlistedNode·엣지만 정리 — dart_filing 소실 사고 재발 방지.

## 5. Export·계약

- **ego 이웃 스키마**: 비상장 이웃은 **`t`(티커) 없이** `{n, kind, type, detail, dir}`.
  상장 이웃은 기존 `{t, n, s, tier, …}` 불변. → **`t` 유무가 상장/비상장 판별자**.
- **`companies_index.json` 불변(2,651 상장만)** — 비상장은 ego 파일이 이름·kind를
  자급하므로 인덱스 조회가 불필요. 부수 효과로 클릭 이동(re-root) 대상에서 자연 배제되고,
  초기 로드 크기(~300KB)도 그대로.
- **V-3 무결성 규칙 한 줄 개정**: "이웃 티커 전원이 index에 존재" → **"`t`가 있는 이웃은
  index에 존재"**.
- `universe.json` rl-string 불변(named400 상호 관계 계약 — 비상장 비관여).
- ego 총량 재실측 게이트(현 ~15MB 추정) — 초과 시 이웃 상위 컷을 export로 전진.
