# Relation 모듈 — 도메인 규칙

## 담당 범위
기업 간 관계 분석 (지분, 공급, 경쟁, 계열) + 그래프 구축

## 관계 유형
- 지분 관계: DART 특수관계자 공시
- 계열 관계: 공정위 대기업집단 계열사 목록
- 공급/경쟁: 업종분류 + 거래 데이터 기반 추론

## 그래프 구조
- 노드: 기업 (corp_code 기준)
- 엣지: 관계 (유형 + 방향)
- 라이브러리: NetworkX → Neo4j (고도화 시)

## 데이터 소스
- DART OpenAPI: 지분·특수관계자
- 공정위: 대기업집단 계열사
- KRX: 업종분류
- DB 저장 테이블: shared/models.py의 RelationData 참조
