## 1. 출발점 — 팀 1차 브레인스토밍 (2026-04-26 공지 요약)

### 문제의식

- **개발 과정의 AI**: Claude Code(바이브 코딩) ✓
- **결과물에서의 AI**: 사실상 거의 없음 ✗
- 심사위원 관점: "AI 활용 대회"인데 화면에는 DART 데이터 시각화만 보임. "우리는 AI로 개발했다"는 차별화 약함.

### 정체성

- "개인투자자 금융 문해력 향상" 교육 플랫폼
- 분식 탐지·투자 추천 같은 위험 라벨링 지양
- "사용자가 스스로 사고하도록 돕는 AI" 방향

### 1차 모듈별 5개 아이디어

| 코드 | 모듈 | 컨셉 | 난이도 |
|---|---|---|---|
| J | financial | 소크라테스식 AI 멘토 (질문을 던지는 AI) | ★★ |
| F | disclosure | 실시간 AI 공시 분석 + 학습 콘텐츠 자동 변환 | ★★★ |
| N | price | 시간여행 멀티턴 시뮬레이션 + 인지 편향 학습 | ★★ |
| (relation) | relation | 공급망·밸류체인 AI 노드 (DART 사업보고서 추출) | ★★★★ |
| S | integration | 그룹 종합 AI 리포트 | — |

### 데이터 신뢰성 원칙 (필수 합의)

1. 정량 데이터(매출·주가)는 LLM에 맡기지 않음 → DB에서 직접 fetch
2. 정성 분석(해석·설명)만 LLM 위임
3. 모든 답변에 출처 표시 (공시 링크·사업보고서 페이지)
4. 출처 없는 추정은 점선·반투명으로 표시
5. 면책 문구 자동 삽입 (`api/middleware/safety.py`)

### 보류 결정

분식 시그널 자동 탐지(D) — 건전한 기업을 잘못 분류할 리스크, 교육 목적과 불일치, "AI가 회계부정을 찾아낸다"는 메시지의 위험.

# Part 1: 시장 조사 + 트렌드 기반 아이디어

## 2. 시장 조사 핵심 — 우리는 이미 누구와 싸우는가

### 2.1 한국 직접 경쟁자 2곳 (이미 운영 중)

#### DartPoint AI (사이냅소프트, 무료, 2024.12 베타) — **가장 위협적**

- DART 공시 → 대화형 AI 분석 + RAG 출처 + 시각화 + MCP 지원
- 자체 sLLM(사이냅 DU LLM) 보유, 한국어 공시 특화
- **약점 (= 우리 기회)**:
  - 학습 모듈 없음
  - 진도 관리 없음
  - 퀴즈 없음
  - 기업 관계 그래프 없음
  - 시뮬레이션 없음
  - "정보 검색 도구"이지 "학습 플랫폼"이 아님

#### 핀들 (Findle, 트레져러) — 2026.04 창업도약패키지 딥테크 선정

- 실시간 뉴스 → 자동 퀴즈 생성, 게임화(XP/Fins/배지), NVIDIA 후원
- sLLM + 행동분석 페르소나 + 맞춤 콘텐츠
- **약점 (= 우리 기회)**:
  - 공시·재무제표 직접 분석 없음
  - 그래프 시각화 없음
  - 한 명의 학생을 깊게 가르치는 1:1 구조 (다중 페르소나·다중 관점 비교 없음)

→ **우리의 공백**: "공시 + 그래프 + 시뮬레이션 + 다중 관점 + K-IFRS 도메인"이 다 합쳐진 곳은 한국에 없음.

### 2.2 글로벌 메가트렌드 5개 (2025-2026)

| 트렌드 | 핵심 | 우리에게 의미 |
|---|---|---|
| **Multi-agent debate** (TradingAgents 54K★) | 7개 역할(분석가·강세/약세 연구자·트레이더·리스크) LLM 토론 | 거래용 → "교육적 청문회"로 번역 |
| **Generative UI** (Google A2UI, SAP) | 사용자 의도 → UI가 매번 동적 생성. Gartner: 75% 기업 도입 예측 | DartPoint 정적 대시보드 대비 차별화 |
| **Digital Twin Finance** (JPMorgan 사용 중) | 기업의 가상 복제본으로 시나리오 시뮬레이트. Gartner: 40% 대기업 도입 예측 | 우리 50개 그래프 + 시계열 = 그룹 단위 디지털 트윈 |
| **Causal-LLM** (Springer 2025) | LLM이 인과 그래프 자동 생성 + 인간 해석 가능 설명 | 공시→주가 변동 인과 사슬 시각화 |
| **Citation-Enforced RAG** (EU AI Act 2026.08 시행) | 페이지 단위 출처 강제 + 증거 부족 시 답변 거부 | 환각 방지 = 차별화 핵심 |

### 2.3 AI 페르소나 — 단순 챗봇이 아닌 "역할극"

- **2026.04 실제 사건**: Customers Bank CEO가 자기 AI 클론으로 30분 IR 콜 진행. 분석가들이 처음엔 못 알아챔
- **교육 적용**: AI가 "역사적/허구의 인물"을 연기 → 사용자는 그 인물과 토론

|---|---|---|

## 4. 1차 새 아이디어 7개 (A~G) — 메가트렌드 × 우리 데이터

### A. AI 청문회 (Virtual IR Theater)

**한 줄**: 사용자가 질문자가 되어 AI 다중 에이전트가 연기하는 가상 IR 청문회를 진행한다.

**메커니즘**:
- 기업 클릭 → 4개 AI 페르소나 등장: **CFO**(공시 대변), **강세 애널리스트**(낙관 해석), **약세 애널리스트**(리스크 지적), **회의적 기관 투자자**(K-IFRS 디테일 추궁)
- 사용자가 질문 입력 → 4명이 각자 답변. 답변마다 **공시 페이지·재무항목 출처 강제**
- 사용자가 채점 → 점수 누적 = 사용자 페르소나 추론
- 시간 흐름: 6개월 뒤 다시 청문회 → AI 페르소나가 "지난번에 당신이 ~를 놓쳤죠"라고 회상

**근거 트렌드**: TradingAgents bull/bear, Customers Bank AI 클론 IR, Citation-RAG, AI persona simulation.

**구현 난이도**: ★★★★ (단계적: MVP는 CFO + 약세 분석가 2명만)

> 이후 사용자 피드백: "AI 청문회는 트렌드를 벤치마킹한 느낌". → Part 2에서 재출발.

### B. 인지 편향 거울 (Cognitive Bias Mirror)

**한 줄**: 사용자의 행동을 분석해 어떤 인지 편향에 빠졌는지 실시간으로 알려주는 AI.

**메커니즘**:
- 시간여행 모드 결정 → AI가 **편향 패턴 8종**(recency, anchoring, herd, loss aversion, confirmation, hindsight, overconfidence, availability)으로 분류
- 누적 데이터 → "당신은 손실회피 편향이 평균보다 32% 강합니다" 시각화 (레이더 차트)
- **반전 훈련**: AI가 사용자의 약점 편향을 자극하는 시나리오 생성 → 극복 시 배지

**구현 난이도**: ★★★

### C. 인과 사슬 자동 생성기 (Causal Chain Explorer)

**한 줄**: 새 공시 → AI가 "이 공시가 왜 일어났고 어떤 결과로 이어지는지" 인과 그래프를 자동으로 그려준다.

**메커니즘**:
- 삼성전자 자사주 매입 공시 → AI가 인과 노드 5-7개 생성:
  ```
  [현금성 자산 80조 ↑] → [자사주 매입 5,000억] → [주당 EPS ↑]
                                                → [경영권 방어]
                                                → [배당 여력 ↓]
  ```
- 각 노드마다 **공시 페이지 + 재무항목 + K-IFRS 조문** 출처 강제
- "왜?" 클릭 → 한 단계 더 깊이
- relation 그래프 위에 "지분 레이어" + "인과 레이어" 토글

**구현 난이도**: ★★★★

### D. Generative UI 워크스페이스 (Adaptive Dashboard)

**한 줄**: 사용자 질문에 따라 대시보드 구성요소가 매번 다르게 자동 생성됨.

- "삼성전자가 위험한가?" → 위험 패널 자동 구성 (부채비율 차트 + 분식 신호 + 공시 빈도)
- "현대차 vs 기아" → 비교 매트릭스 자동 등장
- LLM이 JSON 스키마로 컴포넌트 조합을 출력 → 프론트가 렌더

**구현 난이도**: ★★★★

### E. 그룹 디지털 트윈 (Conglomerate Digital Twin)

**한 줄**: 삼성그룹의 "가상 복제본"을 만들어 위기 시나리오를 시뮬레이트.

- 시나리오 입력: "삼성전자 메모리 매출 30% 급감"
- AI가 그룹 내 8개 계열사의 과거 상관관계 + 공시 패턴 학습 → 가상 결과:
  ```
  삼성SDI: -12% (전기차용 메모리 동반 약세)
  삼성물산: -3% (지분 5% 평가손)
  삼성생명: -1% (지주 효과)
  ```

**구현 난이도**: ★★★★★

### F. 출처 강제 RAG 엔진 (Trustworthy AI Foundation)

**한 줄**: 별도 기능이 아니라 **모든 AI 답변의 기반 인프라**. EU AI Act 2026.08 대비.

- 모든 LLM 답변 → 공시 페이지·재무항목·K-IFRS 조문에 강제로 anchor
- 출처 부족 시 **"답변 거부"가 기본값**
- 점선·반투명으로 "추정" 표시
- 모든 답변에 **신뢰도 점수**(0-100) 자동 계산

**구현 난이도**: ★★★ (필수 기반)

### G. AI 적대 토론 극장 (Debate Theater) — F의 라이트 버전

**한 줄**: 사용자가 고른 공시 → 강세·약세 두 AI가 5턴 토론하는 걸 사용자가 심판.

- 라이브 액티비티로 두 AI 발언이 흘러나옴
- 사용자는 매 턴 "이쪽 손" 클릭 → 누적 점수가 토론 승자 결정
- AI는 자기 점수를 받아 다음 토론에서 강해짐 (개인화)

**구현 난이도**: ★★ (가장 빠른 데모)

## 5. (1차) 메타 차별화 전략 — 한 줄로 정의되는 정체성

세 가지 후보 메시지:

> **(1) "AI가 답을 주는 게 아니라, AI들이 토론하는 걸 본다"** → A·G·E 묶음
>
> **(2) "AI는 모를 때 모른다고 한다 — 출처 없는 답변은 거부한다"** → F 중심
>
> **(3) "AI가 당신의 머릿속을 거울처럼 비춰준다"** → B 중심

**(1) + (2) 결합**이 가장 강력 — 다중 관점 + 신뢰성.

심사위원 한 줄 메시지 후보:
- "**AI가 토론하면, 사용자는 더 잘 사고한다.** 챗봇이 아니라 청문회입니다."
- "**모든 답변은 출처가 있다. 출처가 없으면 답하지 않는다.**"

# Part 2: 재정의 — 트렌드가 아닌 우리만의 무기

## 7. 출발점 재정의

> 사용자 피드백: "AI 청문회도 나쁘진 않지만 트렌드를 벤치마킹한 느낌이라서"

이는 **외부 트렌드에서 시작했기 때문**. 다시 출발점을 잡는다 — "다른 누구도 못 가진 우리만의 자산"에서.

### 우리만 가진 것 5가지

1. **CPA 4명의 회계 감사 시선** — "어디에 빨간 펜을 긋는가"의 자산화
2. **K-IFRS 1024/1028/1109/1110 + 공정거래법 + 자본시장법** 의 한국 도메인 매핑
3. **공정위 계열 ↔ K-IFRS 지분** 두 정의가 같은 기업을 다르게 묶는 **이중 레이어**
4. **한국 공시 특유의 표현 관습** — "검토하고 있다"=거의 결정, "특별한 변동 없다"=변동 있다 같은 행간
5. **공시 → 5일 후 실제 결과** 라벨링 (시간이 진실을 알려준 데이터)

이 중 **외국 모델이 절대 모방 못 하는 건 1, 4** — 여기가 진짜 무기.

## 8. 2차 새 아이디어 8개 (P1~P8) — 트렌드 벤치마크가 아닌 것

### 🔴 P1. 공시 행간 사전 (Reading Between the Lines)

**한 줄**: 한국 공시 특유의 완곡어법을 직역해주는 AI.

```
원문:  "당사는 ~를 종합적으로 검토하고 있습니다"
직역:  "거의 결정됐고 발표만 남았다"

원문:  "현재 진행되고 있는 사항은 없습니다"
직역:  "이번 분기는 없다 (다음 분기는 있을 수 있다)"

원문:  "긍정적으로 검토 중"
직역:  "내부 결정은 났고 이사회 승인 대기"
```

- CPA 팀이 직접 작성하는 **"공시 표현 → 실제 의미" 사전 200개**가 핵심 IP
- AI는 이 사전을 RAG로 참조해서 모든 공시 문장을 자동 직역
- 추가로 **과거 같은 표현이 N일 후에 어떤 결과로 이어졌는지** 통계 함께 표시
  ```
  "검토 중" 표현 → 평균 47일 후 67%가 실제 발표
  ```

**왜 우리만 가능**: 영어 LLM은 한국 공시 관습어를 모른다. 핀들·DartPoint도 직역 안 함. **CPA 팀이 만들면 1주일 안에 사전 200개 가능**.

**구현 난이도**: ★★ (사전이 모든 것, AI는 매칭만)

### 🔴 P2. CPA의 빨간 펜 (Auditor's Markup)

**한 줄**: 감사인이 재무제표를 처음 받았을 때 어디에 표시를 하는지를 AI가 자동 마크업.

- 사용자가 재무제표를 보면 AI가 자동 빨간 동그라미·물음표 표시:
  - 매출 ↑ + 매출채권 ↑↑↑ → 빨간 동그라미 ("회수가 늦어지고 있어요")
  - 영업이익 ↑ + 영업현금흐름 ↓ → 빨간 동그라미 ("이익이 현금으로 안 들어와요")
  - 지배지분 자본 ↓↓ + 비지배지분 ↑ → 노란 마크 ("종속회사로 자본이 빠지고 있어요")
- 마크업마다 **CPA 직접 작성 한 줄 코멘트** + K-IFRS 조문 출처
- "왜 빨간 펜인가요?" 클릭 → 같은 패턴의 과거 사례 3개 자동 검색

**핵심**: 분식 탐지가 아님. 그냥 "감사인의 눈에 띄는 것"을 보여줌. 책임 문구는 "참고 정보".

**왜 우리만 가능**: 감사 경험 = CPA의 직업적 자산. EQS는 점수만 주지만 이건 **시선의 흐름**.

**구현 난이도**: ★★★ (규칙 30~50개 + 시각 마크업 컴포넌트)

### 🔴 P3. 모순 탐지 (Self-Inconsistency Detection)

**한 줄**: 같은 회사가 자기 자신을 얼마나 일관되게 말하는지 점수화.

- CEO 인사말 "성장 중" + 재고자산 +47% + 영업현금흐름 -20% → **모순 점수 73점**
- 1분기 "구조조정 완료" + 4분기 "구조조정 검토" → 같은 해 안에서 어긋남 검출
- 공시(낙관) vs 재무(부담) vs 주가(하락)의 3각 비교
- AI는 "이 회사는 자기 자신을 다르게 설명하고 있어요"라고 알리지 **분식이라고 안 함**

**왜 차별화**: 분식 탐지의 위험은 피하면서 비슷한 통찰. **"AI가 진실을 안다"가 아니라 "AI가 모순을 안다"**가 안전.

**구현 난이도**: ★★★

### 🟡 P4. 파인만 학습법 (Reverse Tutoring)

**한 줄**: AI가 사용자에게 설명을 부탁하고, 어디가 부족한지 알려준다.

- AI: "삼성전자 자사주 매입의 의미를 친구에게 설명한다고 해보세요"
- 사용자가 답 입력
- AI: "잘 설명하셨어요. 다만 **자사주 매입은 보유 vs 소각** 두 가지가 있고 회계 처리가 다릅니다. 당신은 이 구분을 빠뜨렸어요"
- AI: "그럼 보유와 소각의 차이를 다시 설명해주시겠어요?"
- 누적: "당신은 K-IFRS 1109(금융자산) 영역의 이해도가 73%, 1110(연결재무제표) 영역은 41%"

**왜 차별화**: 챗봇·청문회·예측 모두와 완전히 다른 카테고리. **AI가 듣는 입장**. 핀들·DartPoint·TradingAgents 어디도 안 함. 파인만 학습법(Feynman Technique)을 회계 도메인으로 가져온 첫 사례.

**구현 난이도**: ★★★

### 🟡 P5. 숨겨진 연결 (Interlocking Discovery)

**한 줄**: top50 그래프 위에 "이사 겸직·동일 감사인·동일 자문사·공시 시점 동조" 같은 **암묵적 연결** 레이어를 추가한다.

- 명시적 관계(지분·계열) 외에:
  - **이사 겸직**: A사 사외이사가 B사 감사위원
  - **동일 외부감사인**: 같은 회계법인 (삼일·삼정·한영·안진 4대)
  - **공시 동조**: 같은 날 비슷한 시각에 비슷한 유형 공시
  - **지분 변동 동조**: 외국인 지분이 같은 시기에 같은 방향으로 움직이는 그룹
- 그래프에 토글: [지분] [계열] **[이사겸직] [감사인] [공시동조]**

**왜 차별화**: relation 모듈이 가진 데이터를 4배로 활용. 학술 용어로 *interlocking directorate* — 한국에선 거의 시각화 안 됨.

**구현 난이도**: ★★★ (이사·감사인 데이터 추가 수집 필요. DART에 다 있음)

### 🟡 P6. 망한 회사 도서관 (Anti-Pattern Library)

**한 줄**: 과거에 망한 회사들의 5년치 공시·재무를 모아 "전조 패턴 사전"을 만들고, 현재 기업과 비교.

- 대상: 상장폐지·관리종목·회생절차·감사의견 거절 회사들
- AI 자동 추출: "망하기 직전 24개월의 공통 패턴 N개"
  - 감사인 변경 빈도 ↑
  - 공시 정정 빈도 ↑
  - CEO 메시지 길이 변화
  - 영업현금흐름 변동성 ↑
- 사용자가 현재 기업 클릭 → "이 회사는 위기 패턴 12개 중 2개와 일치합니다 (낮은 일치도)"
- **수치보다 패턴**. "예측"이 아닌 "역사적 조회"로 안전한 포지셔닝

**구현 난이도**: ★★★★ (데이터 수집 공수 큼)

### 🟢 P7. 시장 무드 지도 (Galaxy Mood Map)

**한 줄**: top50 별들의 **색이 매일 변하는** 우주맵. 시장 전체 분위기를 한눈에.

- 각 기업 노드의 색 = 3축 합성:
  - **건강도** (재무 EQS) — 채도
  - **분위기** (최근 공시 톤 NLP) — 색상 (파랑=낙관, 빨강=비관)
  - **변동성** (주가) — 깜빡임 빈도
- 시간 슬라이더로 과거 6개월 무드 변화 재생 — 코로나 직전·직후 우주 색깔 차이
- 우리 우주맵의 **시각적 핵심 자산**이 데이터로 살아남

**구현 난이도**: ★★ (이미 우주맵 있음 + 색 매핑만 추가)

### 🟢 P8. 학습 우주 (Personal Learning Galaxy)

**한 줄**: 사용자가 무엇을 봤고 무엇을 모르는지가 자기만의 별자리로 시각화.

- 사용자가 클릭한 기업·공시·개념이 자기 우주에 별로 추가됨
- 별들 사이 연결 = 사용자가 따라간 학습 경로
- AI: "당신은 K-IFRS 1110은 자주 보는데 1024는 한 번도 안 봤어요" → 보완 제안
- 다른 사용자와 비교: "당신의 학습 경로는 73%와 다른 독특한 경로입니다"

**구현 난이도**: ★★

8개를 관통하는 한 줄:

또는 더 강하게:

> **"한국 공시는 행간으로 말한다. 그 행간을 읽는 AI."**

- **한국어·한국 시장 의존**이 약점이 아니라 **방어 해자**가 됨

- 심사위원이 한 번에 이해 가능 ("CPA 팀이 만든 AI" = 신뢰감)

## 11. 한 가지 짚어둘 것 — CPA가 만드는 IP

P1·P2·P3는 모두 **AI보다 CPA 팀의 사전·규칙·루브릭 작성**이 더 큰 일이다. 이게 핵심 —

- **다른 팀**: AI가 만들어주길 기다림
- **우리 팀**: CPA가 도메인 IP를 만들고 AI는 그걸 매칭만 함

5/8까지 우선 순위:
1. **CPA 4명이 한 주 동안 사전·규칙·루브릭 작성** (이게 진짜 차별화 자산)
2. AI는 그걸 바인딩하는 얇은 래퍼

> **"AI가 똑똑한 게 아니라, AI 뒤의 CPA 팀이 똑똑한 겁니다."**

심사위원에게 던질 가장 강력한 한 마디.

## 12. 넥스트 레벨 5개 아이디어

### 12.1 "평행 우주(What-If)" 생성 엔진 (Generative Scenario Engine)

**적용 모듈**: financial, disclosure

**컨셉**: 공시나 재무제표를 읽을 때, AI가 "이 회사의 상황이 조금 달랐다면?" 이라는 가상의 시나리오를 실시간으로 생성하여 비교하게 한다.

**작동 방식**:
- 삼성전자의 '5조 원 자사주 매입' 공시를 읽음
- AI 개입: "만약 삼성전자의 현재 현금 유보율이 지금의 절반 이하였다면, 이 공시는 시장에서 어떻게 해석되었을까요?"
- 사용자가 답변하면, AI는 가상의 재무제표를 동적으로 생성하여 보여주고, 그 상황에서의 리스크를 설명

**교육 가치**: 텍스트(공시)를 컨텍스트(재무 상태)와 분리해서 맹목적으로 호재/악재로 받아들이는 초보 투자자의 치명적인 습관을 고쳐준다. 재무 상태에 따라 같은 공시도 독이 될 수 있음을 시뮬레이션으로 체득.

### 12.2 "섀도우 포트폴리오 (Shadow Portfolio)" 에이전트

**적용 모듈**: price (Time-machine 모듈의 진화)

**컨셉**: 사용자가 과거 특정 시점으로 돌아가 투자를 결정할 때, 사용자 혼자가 아니라 각기 다른 투자 철학을 가진 AI 에이전트들(가치투자자 AI, 퀀트 트레이더 AI, 모멘텀 투자자 AI)과 함께 배틀/협력.

**작동 방식**:
- 2020년 3월 코로나 폭락장. 사용자가 '매도'를 선택
- 워렌 버핏 페르소나 AI: "당신은 매도를 했군요. 하지만 저는 지금이 10년에 한 번 오는 할인 행사라고 생각해서 매수했습니다. 왜냐하면 이 기업의 PBR이 역사적 하단인 0.8배를 뚫었기 때문이죠."

**교육 가치**: 정답을 알려주는 것이 아니라, '동일한 시장 상황과 공시를 보고도 철학에 따라 얼마나 다른 의사결정이 나올 수 있는지'를 다각도로 보여줌. 사용자 자신의 투자 성향(InvestorDNA)을 객관화하는 거울.

### 12.3 법의학 회계사(Forensic Accountant) 방탈출 게임

**적용 모듈**: financial, disclosure (분식 탐지 아이디어의 안전한 교육적 전환)

**컨셉**: AI가 기업의 분식을 '대신' 찾아주는 위험한 기능 대신, AI가 과거 실제 상장폐지/분식회계 사례(대우조선해양, 모뉴엘 등)를 기반으로 '방탈출 게임의 게임 마스터' 역할.

**작동 방식**:
- AI가 과거의 문제적 재무제표와 주석 데이터를 던짐
- "이 기업의 현금흐름표와 영업이익 사이에 수상한 점이 있습니다. 찾아보시겠어요?"
- 사용자가 헤매면 AI가 점진적인 힌트를 제공 ("매출채권 회전율을 다른 경쟁사와 비교해보세요.")

**교육 가치**: 위험한 실시간 라벨링을 피하면서도, 투자자가 반드시 알아야 할 '재무제표의 붉은 깃발(Red Flag)'을 찾는 능력을 게이미피케이션으로 극대화.

### 12.4 '도미노 이펙트' 동적 그래프 생성기 (LLM + 지식 그래프)

**적용 모듈**: relation (공급망·밸류체인 노드의 고도화)

**컨셉**: 정적인 관계망을 보여주는 것을 넘어, 특정 경제 이벤트가 밸류체인을 타고 어떻게 전이되는지 AI가 인과관계 그래프(Causal Graph)를 동적으로 그려가며 설명.

**작동 방식**:
- 사용자가 화면에서 '애플 아이폰 판매량 20% 감소 예측' 이라는 이벤트를 발생시킴
- AI가 실시간으로 노드를 애니메이션으로 확장하며 연쇄 작용을 그림
- "애플(주요 고객사) ⬇️ ➡️ LG이노텍(카메라 모듈 공급) 타격 ➡️ 하지만 삼성전기(경쟁사)에게는 반사이익일까요? 사업보고서를 기반으로 분석해 봅시다."

**교육 가치**: 단순한 기업 정보 암기가 아니라, 글로벌 매크로 환경과 산업 생태계가 톱니바퀴처럼 맞물려 돌아가는 '시스템 사고(Systems Thinking)'를 시각적으로 훈련.

### 12.5 "CEO와의 가상 주주총회" (Debate with the Board)

**적용 모듈**: integration (최종 훈련장)

**컨셉**: 4개 모듈을 다 학습한 후, AI가 해당 기업의 CEO/CFO 페르소나를 장착하고 사용자와 논쟁(Debate) 형태의 롤플레잉 진행.

**작동 방식**:
- 사용자: "최근 영업이익률이 감소했는데, 경쟁사 대비 배당성향이 너무 낮은 것 아닙니까? 주주환원 정책을 늘리세요."
- CFO(AI): "(실제 과거 공시와 어투를 반영하여) 주주님의 의견은 이해하지만, 현재 당사는 HBM 3E 라인 증설에 2조 원의 CAPEX 투자가 시급합니다. 지금 배당을 늘리면 미래 성장 동력을 잃게 됩니다. 이 투자 결정의 근거는 분기보고서 15페이지를 보시면..."

**교육 가치**: 단순히 데이터를 읽는 수동적 학습자에서 벗어나, 기업 측의 논리를 방어해 내거나 설득하는 능동적 투자자로 성장. RAG(검색 증강 생성) 기술의 끝판왕 데모.

## 13. 기술적/전략적 제언 (팀 회의용)

이러한 아이디어들은 단순 API 호출(챗봇)을 넘어, **Agentic AI** (주어진 목표를 달성하기 위해 도구를 사용하고 자율적으로 사고하는 AI)의 개념을 차용.

### 난이도와 임팩트의 밸런스 (Q1에 대한 제안)

가장 먼저, 그리고 가장 획기적으로 데모가 가능한 것은 **12.2 섀도우 포트폴리오 (Price 모듈)** 또는 **12.3 방탈출 게임 마스터**.

기존에 구현해 둔 데이터를 바탕으로 LLM의 프롬프트 엔지니어링과 UI/UX 시퀀스만 잘 짜면 단기간에 "우리 프로젝트는 AI를 이렇게 씁니다!"라고 심사위원을 설득하기 가장 좋다.

### 환각(Hallucination)의 창조적 활용

정보를 요약할 때 환각은 독이지만, **12.1 평행우주 시나리오**와 같이 의도적으로 가상의 상황을 설정하고 추론을 요구할 때 LLM의 생성 능력은 최고의 장점이 된다. 데이터 신뢰성 원칙을 훼손하지 않으면서 생성 AI의 능력을 100% 활용하는 방법.
