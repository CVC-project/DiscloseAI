# 변형 레지스트리 — 기업·산업·포맷 편차의 누적 채록 (VARIATIONS)

> **목적**: galaxy를 기업마다 만들 때 마주치는 **모든 편차**(포맷 버그·산업 구조 차이·기업 고유 사건)를 여기 채록한다.
> 누적된 항목이 곧 "전 기업 커버"의 지도다 — 새 기업 착수 전 **반드시 먼저 읽고**(S0), 완주 후 **새 발견을 기록**(S7)한다.
> 운영 규칙은 [MILKYWAY_GENERATOR.md](MILKYWAY_GENERATOR.md) §9. 같은 패턴이 **2회 이상** 나오면 레지스트리에 머물지 말고 **코드·체커로 승격**한다(승격 후 항목에 `→ 코드화` 표기).

## 기록 형식

`V-###` | 발견(티커·일자) | 층위(수집/구조/고유/포맷) | 증상 → 원인 → 처리(코드화 여부) | 적용 범위(이 회사만/산업/전사)

## ① 수집·분할 층 (sectioner·collector) — 전부 코드화됨

- **V-001** (035420 NAVER, 07-14) — **연결주석 1덩어리 붕괴**: '연결재무제표 주석' 헤더가 목차·요약에 반복 등장(11회)해 region 오시작 + 제목 정규식 `.+?`가 태그를 넘어 삼킴 → 428KB 괴물블록, note 분할 실패. **→ 코드화**: 주1 기점 + tempered dot (`sectioner.py`). 전사 적용. 같은 증상이던 두산·KT&G·삼성SDI·두산에너빌리티도 함께 해제.
- **V-002** (068270 셀트리온·000270 기아, 07-14) — **하위번호 주석 조용한 누락**: `2-1. 중요한 회계정책`·`8-1. 금융자산`(하이픈), `11.1 사용권자산`(점, LG엔솔) — `N.`만 잡는 정규식이 실주석을 통째로 놓침(영업부문·금융자산 등). 어떤 게이트도 미포착(조용). **→ 코드화**: 번호 `\d{1,2}(?:[.\-]\d{1,2})?` (`sectioner.py`). 전사.
- **V-003** (017670 SKT, 07-14) — **별도FS 경계 오인**: 'N. 재무제표의 작성기준'(정상 주석)을 별도재무제표 섹션 시작으로 오인해 주석 1개로 절단(한전·POSCO 동일). **→ 코드화**: SEP 경계를 "제목이 딱 '(별도/개별)?재무제표'로 끝나는 것"만 (`sectioner.py`). 전사.
- **V-004** (035420 NAVER 주37, 07-14) — **마지막 연결주석의 별도FS 과다포획**: 주37(226자)에 별도재무제표 전체(49KB)가 붙음 → note-extractor가 별도 수치를 연결로 오인할 위험. **→ 코드화**: SEP 경계 캡 (`sectioner.py`). 전사.
- **V-005** (전사, 07-14) — **옛 DART 포맷(FY22 이전) 미분할**: FY21·22 보고서는 XML 구조가 달라 1섹션. **처리**: 딥다이브는 최신연도 주석 + 5개년 series(fs_account)로 충분 — 스코프 밖으로 명시(코드 수정 안 함). 단, 5개년 '주석 시계열'(N소스 키)이 필요한 카드가 생기면 재평가. 전사.
- **V-006** (전사, 07-14) — **S0 건강검진 게이트**: V-001~004류(붕괴·괴물블록·결번 과다)를 빌드 전 자동 차단. **→ 코드화**: `sectioner.sectioning_health()` / CLI `--health`. 전사.

- **V-011** (035420 NAVER, 07-14) — **손익이 IS가 아닌 CIS(단일 포괄손익계산서)**: fs_account에 sj_div='IS' 0행, 손익 계정 전부 'CIS'. 제조 골든(IS+CIS 분리)과 다름. **처리**: series SJ_PRIORITY가 이미 흡수(값 정상). 조립·체커에서 sj_div 가정 금지. 산업 무관 회사별 선택지 — 전사 주의.
- **V-012** (금융·지주 5사: 삼성생명·삼성화재·신한·KB·메리츠, 07-14) — **계정 체계 근본 상이**(이자수익 중심, cogs 무의미): 주석 분할 0~1 + series 완결 극소. **처리**: D10 스코프아웃 유지("준비 중") — 표준 템플릿 변형이 아니라 **별도 템플릿** 대상. S0 게이트가 자동 차단.
