> 상태: **검토 대기** (승인 후 DB 점수 산출 시작)
> 작성: 2026-04-27, 브랜치 `feat/financial-v2`

## 1. 왜 v2인가

**현재(v1)의 문제점**
- M1 수정 Jones 모델 (다변량 OLS), M2 Beneish 8지수 가중합, M3 평균·추세·변동성 가중평균 + sigmoid, M4 AR(1) 자기회귀 + robust trim — 모두 학술 회귀모형 기반.
- 점수가 어떻게 도출되는지 **개발자 본인이 한 줄로 설명할 수 없을 정도로 복잡**. 사용자(개인투자자)에게 "이 점수는 이렇게 나왔습니다" 라고 당당히 말하기 어렵다.
- 한국 회계사 1차 시험 합격자 수준의 수학(사칙연산·비율·백분율·단순평균·CAGR)을 넘어선다.

**v2 설계 원칙**
1. **수학 한도**: 사칙연산 + 비율 + 백분율 + 단순 산술평균 + 최대·최소 + CAGR. **회귀·sigmoid·AR(1) 등 추정 모형 불사용**.
2. **각 지표 하나의 문장으로 설명 가능해야 한다.** "M3은 부채를 자본으로 나눈 값이다." 이 정도.
3. **임계값은 한국 시장 통용 기준**(예: 부채비율 100%/200% 라인) 또는 회계학 교재 표준치 사용. 임의 학술 cutoff 금지.
4. **점수 변환은 선형 보간** (구간 끝점 두 개 정의 → 그 사이는 직선). sigmoid·logistic 금지.
5. 출력 0~100점, 5개 지표 단순 평균 → 종합 점수.

## 2. 5개 새 지표

### M1 — 현금이익률 (Cash Earnings Ratio)

**한 줄 설명**: "본업에서 번 이익이 진짜 영업현금으로 돌아왔는가?"

**왜 의미 있는가**: 발생주의 회계상 영업이익(매출 인식 시점에 잡힘)과 실제 영업활동 현금 유입은 시차·차이가 있다. 외상 매출이 회수되지 않거나 재고가 쌓이면 영업이익은 났는데 현금은 안 들어온다. 분식회계의 1차 신호이자, 가치투자에서 "이익 품질"을 보는 가장 기본 지표. **OCF의 "O"가 Operating(영업)이므로 분모도 영업 단계 이익으로 맞춰 매칭 정합성을 확보** — 영업외 일회성 손익(자산처분손익·외화환산·법인세 변동)으로 인한 비율 왜곡을 제거한다.

**계산식**
```
3년 누적 OCF = OCF[t-2] + OCF[t-1] + OCF[t]
3년 누적 OI  = OI[t-2]  + OI[t-1]  + OI[t]

원시 비율 R = 3년 누적 OCF ÷ 3년 누적 OI
```
- OCF: 영업활동현금흐름 (재무제표 현금흐름표)
- OI: 영업이익 (손익계산서, M4와 동일 항목 재활용)
- 3년 누적은 단일 연도의 일회성 변동(법인세 환급 등)을 평탄화하기 위함. **3년 동일비중**(누적 합산 방식) — 분자·분모 모두 단순 합으로 통일해 "3년 합 OCF ÷ 3년 합 영업이익" 한 문장으로 설명 가능.

**점수 변환** (0~100, 선형 보간)

| R 값 | 점수 | 해석 |
|---|---|---|
| ≥ 1.0 | 100 | 영업이익 = 영업현금. 우량 |
| 0.8 | 80 | 80%는 현금화, 20%는 외상·재고 |
| 0.5 | 50 | 절반만 현금. 주의 |
| 0 이하 | 0 | 영업이익은 났는데 현금 유출. 적신호 |

수식: `점수 = max(0, min(100, R × 100))`

**예외 처리**
- 3년 누적 OI ≤ 0 (3년 평균 영업적자): 점수 산출 보류, "3년 누적 영업적자 — 현금이익률 산출 불가" 표시.
- 데이터가 3년 미만이면 가능한 연도만 사용 (최소 1년). 이 경우 note에 "n=2 단축" 등 명시.

**업종 차이**
- 금융업(은행·증권·보험)은 OCF 정의가 비금융과 다르므로(예금 입출금이 OCF에 잡힘) M1 산출은 가능하지만 해석 주의 필요. 최초 단계에서는 동일 공식 적용 후, 결과 보고 별도 처리 여부 판단.

### M2 — 매출 회수 건전성 (AR Quality)

**한 줄 설명**: "매출 늘어났다는데, 그게 진짜 매출인가 아니면 외상으로 잡은 건가?"

**왜 의미 있는가**: 회계학 교재 1장에 나오는 분식회계 패턴 — 매출은 늘었다고 적어놓고 실제로는 매출채권만 부풀려 놓은 경우. **매출증가율보다 매출채권증가율이 더 빠르면 의심 신호**다. 한국 CPA 1차 시험 "재무제표 분석" 문제에서 단골 출제.

**계산식**
```
매출증가율    g_R   = (Rev[t] ÷ Rev[t-1]) - 1
미수채권증가율 g_RC = (RC[t]  ÷ RC[t-1])  - 1

차이 D = g_RC - g_R   (단위: %p)
```
- Rev: 매출액 (손익계산서)
- RC: 미수채권 — 업종에 따라 정의 다름
  - 일반 업종: **매출채권** (재무상태표)
  - **건설·조선·중공업(수주산업)**: **매출채권 + 계약자산(미청구공사)** — 진행기준 회계상 매출은 인식되었으나 발주처에 청구 전인 금액. 해당 업종의 분식 패턴이 매출채권이 아닌 계약자산에서 발생하므로 양 항목 합산 필수.
- D > 0: 외상(또는 미청구공사)이 매출보다 빨리 늘어남 → 의심
- D < 0: 외상이 줄거나 매출보다 천천히 늚 → 양호

**점수 변환** (0~100, 선형 보간)

| D 값 | 점수 | 해석 |
|---|---|---|
| ≤ −10%p | 100 | 외상 비중 감소. 매우 양호 |
| 0%p | 80 | 외상이 매출과 같은 속도로 증가. 정상 |
| +10%p | 50 | 외상이 매출보다 10%p 빠름. 주의 |
| ≥ +30%p | 0 | 매출의 대부분이 외상. 강한 의심 |

수식 (선형 보간):
- D ≤ -10%p → 100
- -10%p < D ≤ 0%p → 80 + (-D / 10) × 20
- 0%p < D ≤ 10%p → 80 - (D / 10) × 30
- 10%p < D ≤ 30%p → 50 - ((D - 10) / 20) × 50
- D > 30%p → 0

**예외 처리**
- 직전연도 매출 또는 미수채권(RC)이 0이거나 결측: 점수 산출 보류, "매출/미수채권 결측" 표시.
- 매출채권 항목이 재무상태표에 없는 회사(일부 서비스업, 금융업 — 대출채권으로 분류): 산출 불가 표시.
- 건설·조선이지만 계약자산 항목이 결측: 매출채권만으로 산출 + note에 "계약자산 결측 — 매출채권만 사용" 표시.

**업종 차이**
- **건설·조선·중공업(수주산업)**: 미수채권 = 매출채권 + 계약자산 (위 계산식 참조). 진행기준 회계 특성상 매출채권만 보면 분식 사각지대 발생.
- 금융업은 매출채권 개념이 다르므로 적용 제외 (note: "금융업 — M2 적용 제외").

### M3 — 부채 건전성 (Debt Health)

**한 줄 설명**: "회사 빚이 자기 돈의 몇 배인가? — 같은 업종 평균과 비교해서."

**왜 의미 있는가**: CPA 1차 "재무회계" 비율분석에서 가장 기본적이고 직관적인 안정성 지표. 부채비율이 높으면 이자 부담↑, 경기 둔화 시 도산 위험↑. **단, 적정 부채비율은 업종마다 본질적으로 다르다** — 건설업(PF·진행기준)·항공·해운·유틸리티는 200%대가 정상이고, IT·소프트웨어는 50%만 넘어도 이례적. 절대 임계값 단일 적용은 자본집약 업종을 일률적으로 저평가하므로, **업종별 임계값 테이블**로 보정.

**계산식**
```
부채비율 D/E = 부채총계[t] ÷ 자본총계[t]
점수        = 선형보간(D/E, 임계값[업종])
```
- 부채총계: 유동부채 + 비유동부채 (재무상태표)
- 자본총계: 자본금 + 자본잉여금 + 이익잉여금 등 (= 자산총계 - 부채총계)
- 보통 % 단위로 표기 (D/E × 100)
- **업종 분류 소스**: DART 산업분류 → KSIC 대분류로 매핑 (TODO: DiscloseAI 보유 분류 코드 확인 후 매핑 테이블 확정)

**업종별 임계값 테이블** (한국은행 「기업경영분석」 최신호 기준 — 우량=100점·양호=80점·주의=50점·위험=0점, 사이는 선형 보간)

| 업종 (KSIC 대분류) | ≤ 우량 | 양호=80 | 주의=50 | ≥ 위험 |
|---|---|---|---|---|
| 정보통신·소프트웨어 | 30% | 60% | 120% | 250% |
| 제조업(일반) | 50% | 100% | 200% | 400% |
| 화학·정유 | 60% | 120% | 220% | 450% |
| 전기·가스·수도 (유틸리티) | 80% | 150% | 280% | 500% |
| 도소매·서비스 | 50% | 100% | 200% | 400% |
| 건설업 | 100% | 200% | 350% | 600% |
| 운수업(항공·해운) | 100% | 200% | 350% | 600% |
| **금융지주** (은행 자회사 주력) | 800% | 1200% | 1700% | 2500% |
| **은행** (단일 은행) | 800% | 1200% | 1700% | 2500% |
| **증권** | 200% | 400% | 600% | 1000% |
| **생명보험** | 700% | 1100% | 1500% | 2200% |
| **손해보험** | 400% | 700% | 1100% | 1700% |
| (위에 없는 업종) | 제조업(일반) 임계값 fallback | | | |
| (기타 금융업: 카드·캐피탈 등) | 금융지주 임계값 fallback | | | |

선형 보간 일반식 (업종별 임계값 [T1, T2, T3, T4] 기준):
- D/E ≤ T1 → 100
- T1 < D/E ≤ T2 → 100 - ((D/E - T1) / (T2 - T1)) × 20
- T2 < D/E ≤ T3 → 80 - ((D/E - T2) / (T3 - T2)) × 30
- T3 < D/E ≤ T4 → 50 - ((D/E - T3) / (T4 - T3)) × 50
- D/E > T4 → 0

**예외 처리**
- 자본총계 ≤ 0 (자본잠식): 0점 + "자본잠식 — 상장폐지 사유" 표시.
- 부채총계 또는 자본총계 결측: 점수 산출 보류.
- 업종 분류 결측 또는 매핑 실패: "제조업(일반)" 임계값으로 fallback + note에 "업종 fallback" 표시.
- 임계값 테이블에 없는 업종: "제조업(일반)" 임계값 fallback.

**업종 차이 — 본 지표 자체에 내재화**
- 자본집약 업종(건설·항공·해운·유틸리티): 임계값 자체가 완화되므로 일률 저평가 문제 해소.
- **금융업**: 부채비율 정의가 본질적으로 다름(예금·고객예수금·책임준비금이 부채로 잡힘). 적용 제외 대신 **업권별 임계값 신설로 보정**:
  - 은행·금융지주: D/E 800~2500% 구간 (NIM 기반 안정적 운영)
  - 증권: 200~1000% (업권 중 가장 낮음 — 자기자본 규제 강함)
  - 생명보험: 700~2200% (장기 책임준비금 비중 큼)
  - 손해보험: 400~1700% (단기 책임준비금 + 보유보험료)
  - **caveat**: D/E는 본질적 안전성 지표가 아님 — 은행은 BIS 자기자본비율, 보험은 K-ICS 지급여력비율이 정도. 본 지표는 보조 신호로만 해석 권고.
  - **금융지주 임계값 = 은행 임계값 적용 근거**: 금융지주 자산의 통상 70~85%가 은행 자회사이므로 은행 D/E 분포와 거의 동일.
- 표본 부족 업종(KOSPI 우량주 universe에서 n이 매우 작은 업종): 한국은행 통계상 분류 그대로 사용 가능 — 통계 자체가 비상장 포함 모집단 기준이므로 우리 universe 크기와 무관.

**유지보수**
- 임계값 테이블은 한국은행 「기업경영분석」 연차보고서 발간 시점(통상 매년 11월)에 갱신.
- 갱신 이력은 본 문서에 기록.

### M4 — 본업 안정성 (Operating Margin Stability)

**한 줄 설명**: "본업이 꾸준히 돈을 내는가, 아니면 들쭉날쭉한가? — 같은 업종 평균과 비교해서."

**왜 의미 있는가**: 회사가 좋은 회사인지의 가장 직관적인 척도 — **본업(영업이익)에서 꾸준히 돈을 내는지**. 매출의 몇 %가 영업이익으로 남는지(=영업이익률), 그 비율이 해마다 비슷한지(=안정성), 두 가지를 같이 본다. **단, 업종별로 본질적 마진과 사이클 진폭이 크게 다르다** — 소프트웨어는 OM 30%가 흔하고, 유통은 2%만 돼도 우수, 반도체는 변동폭 ±20%p가 정상. 절대 임계값 단일 적용은 고마진 업종 변별력 상실 + 저마진/사이클 업종 일률 저평가를 일으키므로, **업종별 임계값 테이블**로 보정.

**계산식**
```
영업이익률 OM[y] = OperatingIncome[y] ÷ Revenue[y]   (y = t-2, t-1, t)

3년 평균 영업이익률 = (OM[t-2] + OM[t-1] + OM[t]) ÷ 3
3년 변동폭         = max(OM[t-2], OM[t-1], OM[t]) - min(OM[t-2], OM[t-1], OM[t])

평균점수    = 선형보간(3년 평균, 평균임계값[업종])
변동폭점수  = 선형보간(3년 변동폭, 변동폭임계값[업종군])
M4         = 평균점수 × 0.6 + 변동폭점수 × 0.4
```
- 업종 분류 소스는 M3와 동일 (DART 산업분류 → KSIC 대분류 매핑, 동일 매핑 테이블 재사용).

**평균 영업이익률 임계값** (한국은행 「기업경영분석」 매출액영업이익률 기반 — 위험=0·손익분기=20·보통=50·우수=80·최우수=100점, 사이는 선형 보간)

선형 보간 일반식 (평균 임계값 [T1..T5], 변동폭 임계값 [V1..V4]):
- 평균 ≤ T1 → 0; T1<평균≤T2 → 0+((평균-T1)/(T2-T1))×20; T2<평균≤T3 → 20+((평균-T2)/(T3-T2))×30; T3<평균≤T4 → 50+((평균-T3)/(T4-T3))×30; T4<평균≤T5 → 80+((평균-T4)/(T5-T4))×20; 평균 > T5 → 100

**예외 처리**
- 매출 = 0 또는 결측인 해 제외. 유효 연도가 2년 미만이면 점수 산출 보류.
- 2년만 있을 경우: 변동폭은 단순 차이로 계산, note에 "n=2 단축" 표시.
- 업종 분류 결측 또는 매핑 실패: "제조업(일반)" + "일반 업종" fallback + note에 "업종 fallback" 표시.
- 임계값 테이블에 없는 업종: "제조업(일반)" + "일반 업종" fallback.

**업종 차이 — 본 지표 자체에 내재화**
- 고마진 업종(소프트웨어·바이오): 임계값 자체가 높게 설정되어 변별력 확보 (OM 25%가 만점이 아닌 80점대).
- 저마진 업종(유통·종합상사): 임계값이 낮게 설정되어 OM 4%만으로도 우수 평가.
- 사이클 업종(반도체·조선·정유·화학·해운·자동차): 변동폭 임계값이 5배 가량 완화되어 본질적 사이클성으로 인한 일률 저평가 해소.
- **금융업**: 영업수익(이자·수수료·보험료) 분모로 산출 가능. 업권별 본질 차이를 반영해 5개 행으로 분할 — 은행·금융지주(NIM 30~45%)·증권(시장 의존, 변동 큼)·생보(장기 위험률, 변동 작음)·손보(재해·요율 변동, 일반 수준).
  - **caveat**: 금융업 영업이익은 회사·연도별 회계기준 변경(K-IFRS 17 보험계약 등) 영향을 크게 받으므로 절대비교는 보조 신호로만 권고.
  - **금융지주 임계값 = 은행 임계값 적용 근거**: 자산·이익의 70~85%가 은행 자회사이므로 OM 분포 거의 동일.
  - 카드·캐피탈 등 기타 금융업: 금융지주 임계값 fallback.

**유지보수**
- 평균 임계값은 M3와 함께 한국은행 「기업경영분석」 발간 시점에 일괄 갱신.
- 변동폭 임계값은 사이클 본질에 따른 구조적 수치이므로 갱신 빈도 낮음 — KOSPI 분포 검토 시점에 재평가.

### M5 — 자본 성장성 (Equity Growth)

**한 줄 설명**: "회사가 벌어서 자기 돈을 키워나가고 있는가?"

**왜 의미 있는가**: 회사가 돈을 벌면 그 일부는 배당으로 주주에게 돌아가고, 일부는 회사 안에 쌓여(이익잉여금) **자본총계가 커진다**. 이 자본 성장이 곧 "주주의 몫이 커지는 속도"다. CPA 학생도 직관적으로 와닿는 장기 가치 지표.

**계산식** (CAGR — 연평균 성장률)
```
자본 CAGR = (자본총계[t] ÷ 자본총계[t-2])^(1/2) - 1
```
- 자본총계[t]: 최근 회계연도 자본총계
- 자본총계[t-2]: 2년 전 자본총계
- (^)^(1/2): 제곱근 (2년간 성장의 연평균)
- CAGR은 화폐의 시간가치 단원에서 학습하는 개념 — CPA 1차 재무관리 범위.

**점수 변환** (0~100, 선형 보간)

| CAGR | 점수 | 해석 |
|---|---|---|
| ≥ +10%/yr | 100 | 강한 자본 성장 |
| +5%/yr | 75 | 양호 |
| 0%/yr | 50 | 정체 |
| -5%/yr | 25 | 자본 잠식 진행 중 |
| ≤ -10%/yr | 0 | 심각한 자본 감소 |

수식: `점수 = max(0, min(100, 50 + CAGR × 500))`
(즉 CAGR 1%p당 5점 가감, 중심 0%/yr=50점)

**예외 처리**
- 자본총계[t-2] ≤ 0: CAGR 정의 불가 → 0점 + "2년 전 자본잠식" 표시.
- 자본총계[t] ≤ 0: 0점 + "현재 자본잠식 — 상장폐지 사유" 표시.
- 데이터가 2년 미만이면 점수 산출 보류.

**업종 차이** — 없음. 모든 업종에 동일 적용 가능.

## 3. 종합 점수와 등급

```
EQS Total = (M1 + M2 + M3 + M4 + M5) ÷ 5
```

각 지표가 산출 보류된 경우 **해당 지표를 제외하고 평균** (예: M2 적용 제외인 금융업은 4개 평균).

**등급 (한국 시장 통용)**

| Total | 등급 | 의미 |
|---|---|---|
| 80~100 | A | 우수 |
| 65~79  | B | 양호 |
| 50~64  | C | 보통 |
| 35~49  | D | 주의 |
| 0~34   | F | 취약 |

### 외부감사의견 캡 (Audit Opinion Cap)

**왜 필요한가**: 본 5개 지표는 모두 재무제표 숫자를 입력으로 사용한다. 그 숫자 자체의 신뢰성에 외부감사인이 이의를 제기한 경우(부적정·의견거절·한정), 점수 산출 결과가 무엇이든 신뢰할 수 없다. 따라서 **감사의견을 점수 외부의 상한 캡(cap)**으로 적용한다.

| 감사의견 | 처리 |
|---|---|
| 적정 (Unqualified) | 캡 없음 — 산출된 등급 그대로 |
| 한정 (Qualified) | **등급 1단계 강등** (예: B → C, A → B). Total 점수는 그대로 표기하되 등급만 강등 |
| 부적정 (Adverse) | **등급 자동 F** + "감사의견 부적정 — 점수 신뢰 불가" 표시 |
| 의견거절 (Disclaimer) | **등급 자동 F** + "감사의견 거절 — 점수 신뢰 불가" 표시 |
| 결측 / 미공시 | "감사의견 미확인" 표시 + 등급 한 단계 잠정 강등 또는 보류(운영 정책에 따라) |

산출 의사코드:
```
raw_total = mean(applicable Mx scores)
raw_grade = grade_from_total(raw_total)

if audit_opinion == "Adverse" or "Disclaimer":
    final_grade = "F"
elif audit_opinion == "Qualified":
    final_grade = downgrade_one(raw_grade)
else:
    final_grade = raw_grade
```

**적용 대상 회계연도**: 점수 산출에 사용된 가장 최근 회계연도(t)의 감사의견. 과거 연도(t-1, t-2)에 비적정 이력이 있으면 사용자 표시(note)로만 알리고 등급은 강등하지 않음.

## 5. 데이터 요구사항

### 재무제표 기준 — 연결 우선 원칙

본 EQS는 **연결재무제표를 1순위, 별도(개별)재무제표를 2순위**로 사용한다.

| 우선순위 | 사용 기준 | 적용 케이스 |
|---|---|---|
| 1순위 | 연결재무제표 (K-IFRS 연결) | KOSPI 우량주 대부분 — 모회사+자회사 합산 실적 반영 |
| 2순위 | 별도재무제표 (K-IFRS 별도 / K-GAAP) | 연결 미공시 회사, 자회사 없는 단일법인 |
| 산출 보류 | 둘 다 결측 | "재무제표 결측" 표시 |

**왜 연결 우선인가**: 지주사·다국적 기업은 별도재무제표만 보면 매출·이익·자산이 모회사 단독으로만 잡혀 실체가 왜곡된다. 사용자가 보는 "회사"의 실제 실적은 연결 기준이며, 한국 주식시장 분석에서도 연결이 표준.

**일관성**: 한 회사에 대해 모든 5개 지표는 동일 기준(연결 또는 별도)으로 산출. 지표마다 기준이 섞이지 않도록 함. 데이터 소스에 기준 표시(consolidated / separate) 메타데이터 필드 명시.

### 항목별 필요 데이터

각 지표가 필요한 재무제표 항목 (이미 `FirmYear`에 존재):

| 지표 | 필요 항목 | 소스 |
|---|---|---|
| M1 | operating_income, operating_cashflow | 손익·현금흐름표 |
| M2 | revenue, accounts_receivable, **contract_assets** (건설·조선만) | 손익·재무상태표 |
| M3 | total_liabilities, total_equity, **industry_code** (KSIC 대분류 매핑) | 재무상태표 + DART 산업분류 |
| M4 | revenue, operating_income, **industry_code** (M3과 공유) | 손익계산서 + DART 산업분류 |
| M5 | total_equity | 재무상태표 |
| (공통) | **audit_opinion** (적정/한정/부적정/의견거절), **statement_basis** (consolidated/separate) | 감사보고서 + 재무제표 메타 |

기간: **최근 3개년** (M5는 2년 전 자본까지). 모든 지표가 우리 DB의 기존 5년치 데이터로 산출 가능. 감사의견·재무제표 기준은 신규 수집 필요 항목.

**우선순위**: KSIC 코드 + 회사명 보조 룰 동시 만족 시 분류. 경계 케이스(예: "한국금융지주" — 증권 자회사 주력이지만 회사명에 "금융지주" 포함)는 **회사명 룰 우선** 적용 → 금융지주 분류로 처리. 분류 결과는 정기 검토 시 수동 보정 가능.

## 6. 한계와 검토 의견 요청

### 해결됨 (지표·정책에 내재화)

1. **금융업 처리**:
   - **M2** (매출채권 부적합): 여전히 적용 제외, 종합점수는 4개 지표 평균.
   - **M3·M4**: 금융업 5개 행(금융지주·은행·증권·생보·손보) + 카드/캐피탈 fallback으로 임계값 신설 — 적용함. 금융지주는 은행 임계값 사용(자산의 70~85%가 은행 자회사). 분류 룰은 5장 참조.
   - **caveat**: D/E는 BIS, OM은 K-IFRS17 영향 등으로 본질적 안전성 지표가 아님 — 보조 신호로 권고. 향후 BIS·K-ICS 등 업권 지표 직접 파싱은 별도 과제.
2. **사이클 산업의 M4**: 변동폭 임계값을 사이클 업종군에 한해 5배 가량 완화 (지표 내재화).
3. **외부감사의견 미반영** (1차 보완 A): 감사의견 캡 도입 — 부적정·의견거절은 자동 F, 한정은 1단계 강등 (3장 참조).
4. **M2 미청구공사 사각지대** (1차 보완 B): 건설·조선·중공업 업종은 매출채권 + 계약자산을 합산 (M2 본문 참조).
5. **연결 vs 별도 재무제표 기준** (1차 보완 D): 연결 우선 원칙 명시 + 한 회사 내 일관 적용 (5장 참조).

### 미해결 (운영·재검토 대상)

6. **임계값 보정**: 한국 시장 통용 기준 사용 중이나, 우리 universe(KOSPI 48개) 분포 보고 미세 조정 필요.
7. **3년 윈도우 vs 5년 윈도우**: M1·M4는 3년, M5는 2년 사용. 5년 확장 시 사이클 평탄화↑/누락 보류율↑ trade-off.
8. **M5의 자본 환원 미반영**: 자사주 매입·소각 활발한 회사는 자본 CAGR이 부당하게 낮게 나옴. "총주주환원 CAGR"로 확장 가능하나 단순성 저하 — 결과 분포 보고 판단.
9. **적신호 1개 무시 문제**: 한 지표가 0점이어도 평균에 묻힘. 향후 "최저 지표 점수" 병기 또는 적신호 강등 룰 도입 검토 (1차에서는 미반영).
10. **시점 지연(timeliness)**: 사업보고서 결산 후 90일 공시 → 점수가 최대 ~15개월 lagged. 분기보고서 활용은 별도 작업.
11. **EQS의 본질**: 본 점수는 "재무 건전성"이지 "투자 매력도/저평가도"가 아님 — PER·PBR·시가총액 등 시장 지표 미포함. 사용자 노출 시 명시 필요.
