# Financial 모듈 — 도메인 규칙

## 담당 범위
재무제표 수집 + EQS(이익 품질 점수) 5개 모듈 계산 + 재무 요약

## EQS v2 5개 모듈 (설계: `modules/financial/EQS_V2_DESIGN.md`)
- M1 현금이익률: 3년 누적 OCF ÷ 3년 누적 영업이익 → 점수 = 비율 × 100 (0~100 클립)
- M2 매출 회수 건전성: (미수채권증가율) - (매출증가율). 수주산업(건설·조선)은 매출채권+계약자산 합산. 금융업 적용 제외.
- M3 부채 건전성: 부채총계 ÷ 자본총계. 업종별 임계값(IT 30~250%, 제조 50~400%, 건설 100~600%, 은행 800~2500%).
- M4 본업 안정성: 3년 영업이익률 평균(60%) + 변동폭(40%). 업종별 임계값(SW·바이오 고마진, 유통 저마진, 사이클 산업 변동폭 5배 완화).
- M5 자본 성장성: 2년 자본 CAGR. 점수 = 50 + CAGR×500 (클립 0~100).

## 업종 처리 (v2 — 임계값 테이블 내재화)
- 회사명 → 업종 분류: `eqs/industry_v2.py` (KOSPI 48 hardcoded; 향후 KSIC API 연동)
- 금융업(M2 제외 + M3·M4 업권별 임계값): 금융지주·은행·증권·생보·손보 5개 행
- 종합점수: 5개 모듈 단순 평균. score=None 모듈은 자동 제외 (금융업은 4개 평균).
